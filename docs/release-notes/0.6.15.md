## 新功能

- **收起实时画面**：Agent 持续输出时，可以收起某个 Pane 的实时画面来省电。收起后 Pane 中间显示一张小卡片，写着 Agent 名称和任务状态（处理中 / 等待你确认或输入 / 空闲 / 已完成）。进程照常运行，通知照常弹出。入口：终端右键菜单、「显示 ▸ 收起实时画面」（⇧⌘B）或命令面板。点卡片上的按钮或按 Return / Space 恢复。
- **Pane 放大按钮**：分屏时把鼠标移到 Pane 顶边，右上角 `×` 左边多了一个放大按钮。点它把这个 Pane 放大到整个内容区，再点一次还原原来的分屏。快捷键 ⇧⌘↩ 照旧可用，也可以在「设置 ▸ 快捷键」里修改。
- **设置页**：左侧分区换了新图标，点击时有小动画；内容往下滚动后，顶部会显示「设置 / 当前分区」。

## 修复

- 修复「设置 ▸ 控制 ▸ 自动补全」里「接受候选」和「候选面板」选了不生效、跳回第一项的问题。
- 修复另一个 Aster 正在使用某个后台保活终端时，点「重新附加」一直附加不上的问题。现在点一次就会接管过来。

## 改进

- Agent 停在确认表单等画面不动时，不再每 0.3 秒读一次屏，长时间等待更省电。
