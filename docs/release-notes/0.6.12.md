## 新功能

- 打开的文件支持 ⌘F 查找内容。源码、Markdown / HTML / SVG 预览、Agent 会话记录和 PDF 都能查。输入即查，↩ 下一个，⇧↩ 上一个，Esc 关闭；源码里显示「当前 / 总数」，并支持区分大小写和正则。
- Ghostty 终端的触控板滚动改为按像素平滑滚动，不再一行一行地跳；手势结束后自动对齐到整行。滚动距离也按屏幕缩放换算，Retina 屏上内容跟手移动。
- Ghostty 终端支持「滚过末尾 / 开头」。这两项设置以前只在旧终端引擎里生效。

## 改进

- Claude Code 全屏模式下快速滑动触控板，手指停下后画面马上停，不再继续追滚约 0.2 秒。

## 修复

- 修复 Codex 有时被识别成 Claude Code 的问题。Codex 的终端标题以转圈动画开头，以前被当成 Claude 的标志；现在不再这样判断，并会读取前台进程确认是哪个 Agent。识别错了也会被 Agent 自己的上报纠正。
- 修复同一目录开两个 Agent 时，侧栏标签显示成另一个会话标题的问题。
- 修复终端滚动条遮挡最右几列文字的问题。滚动条现在有自己的位置，平时隐藏，滚动或指针移到右侧时出现。
