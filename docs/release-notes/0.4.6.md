## 命令补全大幅增强

- 补全候选现在会读取项目里的活数据：git 分支与 remote、`package.json` 的 scripts、
  Makefile 的 target、Homebrew 已装的包等，都能直接补出来，不用再手打。
- 排序换成跨来源统一打分：常用的命令靠「最近用得多」自然浮到前面，冷门的历史记录
  不会再压住真正贴合当前输入的子命令和选项。
- 命令名刚打完、还没敲空格时也会列出它的子命令与选项（`docker` 从 1 条变 62 条）。
- 候选按「补全后的完整命令行」去重，历史和规格不再重复占两行。
- 候选面板：超过 8 条可滚动，新增右侧描述栏显示选中项的完整说明（窄 Pane 自动降级
  回行内描述），选中行改为强调色淡染 + 前导标记条。
- 自动弹出的候选面板在你按方向键之前不会吞掉回车，命令照常提交。
- 装了 zsh-autosuggestions 之类插件时，Aster 的行内建议会被插件挡住而不可见；此时
  按 Tab 改为打开候选面板，既不会插入你没看见的文本，也不会让你完全看不到候选。
- `aster learn` 支持三种目标：目录、PATH 上的命令（自动探测 `--help` 生成规格）、
  整行命令；`aster ignore` 与它一一对应地撤销。

## 修复

- 左右分屏时，侧栏标签的 Agent 图标严格跟随当前聚焦的 Pane。左边跑 Codex、右边是
  普通 shell 时，点右边不会再显示 Codex 图标。
- Agent 自己在标题里转动 ✳/◐ 之类的字符时，不再额外叠加一个 Aster 图标。
- 上一条命令失败后，新的空命令行上不会再画出整条纠错建议——它此前会和 shell 自己的
  历史建议重叠成一团。
- Pane 顶部的拖动把手与关闭按钮恢复为「鼠标靠近才出现」。此前分屏或调整窗口大小后
  它们会永久显示在所有 Pane 上。
