## 改进

- AI 用量面板改成菜单栏控件的手感。点状态栏图标时，面板每次都从图标正下方展开，不再记住上次位置——多屏或换 Space 后不会再出现在与图标无关的屏幕上（只记住你调过的尺寸）。展开时有一段从菜单栏拉出来的高度动画，指针离开面板和图标 0.35 秒后自动收起，不用再点一次关闭；系统开了「减弱动态效果」就不播动画。拖尺寸中、有弹出窗口时不会误收起。
- 移除 Pane 底部的 Agent 用量条。菜单栏的 AI 用量面板已经覆盖配额、Token 与会话三块内容，底部再放一条重复且占用终端行数；旧的用量条还只认 Claude 与 Codex 两家，跑 Codex 时可能显示成 Claude 的用量。顺带去掉每个 Agent Pane 的后台文件监听。

## 修复

- 修复从别的程序切回 Aster 会被拉到出错标签的问题。点 Dock 图标、点程序坞条目或 `open -a` 都会触发这段逻辑，旧实现只要还有标签挂着上一条命令的失败徽章就把焦点抢走，即使这个失败你早就看过、即使「出错时变红」是关着的。现在只有 Dock 图标真的标红时才跳一次。
- 网格尺寸提示（Pane 中央的「列 × 行」）只在拖动窗口边缘改变窗口大小时出现。此前切换标签或 Pane 时也会闪一下，因为那些操作同样会改变终端行列数。
- 修复网格尺寸提示里的文字上下留白不对称，看起来贴着气泡顶部。
