## Pane 底部用量条

- Claude Code 或 Codex 运行时，Pane 底部显示一条用量条：Claude 显示 5 小时与每周配额，Codex 另含当前会话上下文占比；达到 80% 变为警示色，悬停查看重置时间。
- Claude 的配额直接读取官方 `/usage` 接口，与 Claude 自己的 `/usage` 面板数值一致，有 Claude 运行时每分钟刷新、每轮回复结束再更新一次。首次会请求一次钥匙串访问授权，选「始终允许」即可；不改动 `~/.claude/settings.json`。
- 点击用量条会在该 Pane 的 Agent 里打开完整统计面板（Claude Code 运行 `/stats`，Codex 运行 `/status`）。
- 可在“设置 → 智能体 → Pane 底部显示用量条”关闭。

## 链接与路径打开

- 修复 Command 点击 `.app`、可执行文件或二进制文件路径时被错误送进编辑器并报错的问题：这些目标现在直接交给系统打开，目录与文本文件仍按设置在 Aster 内打开。

## Agent 会话结束后的续接

- 已安装 lifecycle hook 的 Agent（Claude Code、Codex、Grok Build 等）退出时，窗口顶部提示该会话的 resume 命令（如 `claude --resume <session-id>`），并记住这个项目目录最近一次的会话。
- 之后在同一目录的终端里，空 prompt 的 inline 补全直接给出整条 resume 命令，候选面板里它排第一；按 Tab 接受、回车执行。命令按 Agent 区分：Claude / Grok 是 `--resume`，Codex 是 `codex resume`，OpenCode / Kimi / Pi 是 `--session`。不会自动执行任何命令。

## 用量条修复

- Claude 的 `/usage` 接口限流很紧，旧版每分钟轮询会把接口打成 429，又把 429 误判为未登录而一直不显示用量条。现在改为每 5 分钟轮询、回复结束的补拉至少间隔 3 分钟，被限流时按 `Retry-After` / 指数退避重试，恢复后自动出数；上次拉到的数字会缓存到本机，重启后立即显示，悬停可见数据更新时间。相关失败会写入诊断日志。
- 账号有按模型单独计费的每周配额（如 Fable）时，用量条会多显示一个以该模型名标注的周窗口。
