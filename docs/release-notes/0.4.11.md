## Pane 底部用量条

- Claude Code 或 Codex 运行时，Pane 底部显示一条用量条：Claude 显示 5 小时与每周配额，Codex 另含当前会话上下文占比；达到 80% 变为警示色，悬停查看重置时间。
- Claude 的配额直接读取官方 `/usage` 接口，与 Claude 自己的 `/usage` 面板数值一致，有 Claude 运行时每分钟刷新、每轮回复结束再更新一次。首次会请求一次钥匙串访问授权，选「始终允许」即可；不改动 `~/.claude/settings.json`。
- 点击用量条会在该 Pane 的 Agent 里打开完整统计面板（Claude Code 运行 `/stats`，Codex 运行 `/status`）。
- 可在“设置 → 智能体 → Pane 底部显示用量条”关闭。

## 链接与路径打开

- 修复 Command 点击 `.app`、可执行文件或二进制文件路径时被错误送进编辑器并报错的问题：这些目标现在直接交给系统打开，目录与文本文件仍按设置在 Aster 内打开。
