## 画中画

- 使用 macOS 系统画中画镜像终端，支持固定当前 Pane 或跟随活动 Pane。
- 原终端保留输入、滚动和网格尺寸；暂停只冻结镜像，不暂停运行中的命令。
- 修复 macOS 26 下画面空白、缩放裁切及模式切换时焦点跳回旧 Pane 的问题。

## 界面与交互

- 右栏页签与窗口标题行对齐，修复右栏分隔线与背景同色而不可见的问题。
- 修复 One Light 主题下 Pane 分隔线不明显的问题。
- 鼠标静止在链接上时，按下 Cmd 立即显示手形；松开后恢复原指针。
- 改进自动补全建议对齐，并保留提示符中的已有输入。

画中画当前支持终端 Pane，非终端 Pane 会提示不可用。
