## 远程机器

- 把另一台机器当作和本机同等的工作机器：终端、标签、分屏都运行在那台机器的后台会话服务里。关闭 Aster、断网、换一台 Mac 再连，进程和布局都还在。
- “文件 ▸ 添加机器…”支持 SSH 别名、`user@host`、`ssh://user@host:port` 与 OrbStack 的 `root@ubuntu@orb`，只使用你现有的 OpenSSH 密钥与 known_hosts。远端没有服务时，从 App 内置产物一键安装；已有旧版本时，“更新远端服务…”先列出影响再替换，旧版本保留可回退。
- 侧栏左下角新增机器切换器：显示当前机器与连接状态，点开切换、添加机器。“文件 ▸ 切换机器”也可以。
- 远端 Agent 与本机一样：连上机器时探测远端装了哪些 Agent CLI 并显示在机器行；一键把 Aster 的 Agent 集成装到远端，远端 Claude Code、Codex、Grok 的运行状态、等待输入和完成通知随即出现在侧栏与 Dock。
- “新建远端 Agent…”从远端清单里选一个 CLI，直接以 Agent 身份开标签；Agent 退出后落回远端 Shell。
- 远端进程退出后窗格显示“远端进程已结束”，可重新启动（跑过 Agent 的窗格会用 `--resume` 恢复对话）或关闭标签。服务替换与冷重启后的窗格自动恢复。
- 远端受管终端支持 `⌘V` 上传剪贴板图片并粘贴远端路径、远端自定义命令、只读观察与显式接管；手机或平板通过 SSH 运行 `aster-session` 终端客户端也能浏览工作区、切换窗格、输入与分离。

## 稳定性

- libghostty 配置校验失败不再让所有窗格启动失败：无法识别的配置项按警告显示，终端照常启动。
- 冷恢复出来的新 Shell 改为登录交互 Shell，PATH 与提示符和平时一致。
