## 新功能

- **窗口内工作区**：一个窗口里可以有多个工作区，每个工作区是一组标签，比如一个项目一个。左侧栏上方列出工作区，点「+」新建，点一个就只显示它的标签；标签区标题写着「<工作区名> · 标签」，一眼看出标签属于哪里。切走的工作区里，终端、Agent 和通知照常工作，点通知会切回对应的工作区。双击重命名，右键删除；右键标签可以「移到工作区」。也可以用「文件 ▸ 新建工作区…」（⌘⇧N）、「下一个工作区」（⌃⌘]）和「上一个工作区」（⌃⌘[）。标签栏放在顶部或底部时，标签条最左边有工作区按钮。升级后，原来的标签都放进一个叫「默认」的工作区。
- **SSH 主机管理**：新增「设置 ▸ 主机」，保存常用的 SSH 主机：端口、用户、认证方式、私钥、跳板机、端口转发、代理、「只用指定私钥」和 known_hosts 文件都能填。可以从 `~/.ssh/config` 导入。口令只存在 macOS 钥匙串里，登录成功后才保存。
- **原生 SSH 标签**：打开已保存的主机，得到一个直接是远端 Shell 的标签，重启 Aster 后会重新连接。在 Open Quickly 里按 ⌘S 切到 SSH，输入 `user@host` 就能快速连接、保存为主机或添加为机器。在本地标签里手敲 `ssh` 连上后，右键标签「保存为主机…」会预填地址。遇到兼容问题可以在「设置 ▸ 高级 ▸ SSH 引擎」切回 OpenSSH。你自己在终端里敲的 `ssh` 不受影响。
- **远端多工作区**：一台远程机器可以有多个工作区。切走的工作区只断开画面，里面的任务继续跑。添加机器时可以直接选一台已保存的主机。
- **补全按习惯排序**：补全会记住你常用的命令、子命令、选项和参数，换到新目录也能先补出来；还会参考上一条命令，比如 `git add` 之后优先补 `git commit`。`cd` 只推荐现在还存在的目录。
- `aster-cli` 新增 `host list` 与 `workspace list / open / new`。

## 修复

- 修复开启「本机后台保活」后，在 Pane 里输入 `exit` 不关闭，还提示「远端进程已结束」的问题。现在会像普通 Pane 一样关闭。
- 修复 Open Quickly 在两个目录里都有同名 Agent 会话记录时让 Aster 崩溃的问题。
- 修复点状态栏图标打开 AI 用量窗口后，鼠标从图标直接移开时窗口不自动收起的问题。
- 修复本机后台保活时 Agent 输出持续闪烁的问题。
- 修复恢复的 Pane 光标变成方块、Claude Code 标志旁出现黑块的问题。
- 修复 Codex 退出后光标上移一行的问题，以及恢复的后台保活 Pane 收不到 Agent 状态、Codex 会话标题不显示的问题。
- 关闭后台保活的 Pane 时不再卡住界面。
