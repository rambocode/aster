## 新增

- SSH 到服务器后，右侧详情面板的 Files 页变成「服务器文件」、Info 页变成「服务器监控」，`exit` 回到本机后自动恢复本地内容。远程工作模式下的远端终端同样可用。
- **服务器文件**：跟随远端 Shell 上报的当前目录，在终端里 `cd` 过去面板就跟着走。可以进子目录、返回上级、复制路径、把 `cd` 预填到终端、下载文件到本机，也能拖文件进面板上传到当前目录。目录超过 2000 项会标注「已显示 2000 / N 项，已截断」。
- **服务器监控**：分「概览 / 磁盘 / 进程 / 端口」四页，点页签切换，一次只看一类指标。概览是主机名与系统版本、运行时长、负载与 CPU、内存和 Swap；磁盘列出各挂载点用量（同一块盘挂到多个路径时只列一条）；进程是一张三列表格（进程 / CPU / 内存），点表头排序、箭头朝下是从大到小，点某一行能看它的 PID、用户、占用和完整命令行；端口列出监听中的 TCP/UDP 与占用它的进程。面板可见时每 3 秒刷新，切页不会重连服务器。
- 远端目录要靠远端 Shell 上报。面板会提示「未收到远端目录上报」并提供「安装远端集成」，点一下就把集成脚本装到远端 `~/.config/aster/`，安装前会列出将要改动的远端文件让你确认。装完重新登录或执行 `exec $SHELL` 生效。不想装也可以直接浏览 `$HOME` 或手动输入路径。
- 新增设置「Shell → Shell 集成 → SSH 连接复用」（默认开启，需要「SSH 集成」也开着）：Aster 启动的终端里 `ssh` 会自动带上 OpenSSH 的 ControlMaster 选项，把已认证的连接复用给上面两个面板，面板因此不需要再认证一次。你自己定义的 `ssh` 函数或别名优先，Aster 不会替换它。开关只影响之后新建的终端。

## 修复

- 在一个 Pane 里拖选文字后点另一个 Pane，终端不再卡在选择模式，新 Pane 立刻能正常输入。
- 拖完分屏分隔线后把指针移开，光标会复位成箭头，不再一直停在左右箭头的拖动形态。
- 用 ↑ 调出历史里的 `ssh` 命令再执行，左侧标签重新按远端主机分组。之前这种情况下键盘记录拿不到完整命令，第二次执行同一条 `ssh` 就不再建立远端分组了；接受 Shell 自动建议或 Tab 补全后执行也是同样的问题。

## 优化

- 详情面板拖窄之后会自动精简次要列：进程隐去 PID、端口隐去监听地址、文件隐去修改时间，把宽度让给真正要读的那一列；拉宽后自动恢复。
