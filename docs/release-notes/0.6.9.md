## 新增

- 新增「AI 用量」面板。在「设置 → 智能体 → 状态栏 AI 用量」打开，或用菜单「显示 → 显示 AI 用量」／命令面板「显示 AI 用量」（会顺手打开开关）。打开后系统状态栏多一个图标，旁边是各账号的已用百分比，到 80% 变警示色、95% 变红；有 Agent 在等你输入时图标上亮一个红点。点图标弹出一个磨砂浮动窗，可拖动、可缩放、记住位置，切到别的应用或桌面也留在最前。浮动窗分三页：**配额**——Claude、Codex、Cursor 各一张卡，显示订阅档位（Max 20x、Pro 等）、各窗口的进度条与「多久后重置」，底部可切换「已用 / 剩余」两种口径；**Token**——按今天 / 7 天 / 30 天 / 全部统计本机用掉的 token，分输入、缓存写入、缓存读取、输出四列，可按 Agent 和按项目看排行，点项目展开它过去一年的活动热力图；**会话**——所有窗口里正在跑的 Agent 一人一张卡，显示等待输入 / 运行中 / 空闲，以及该 Pane 整棵进程树的 CPU、内存和进程数，等待输入的排在最前，点卡片跳回那个 Pane。
- Token 统计覆盖 Claude Code、Codex、Pi、Grok Build、Gemini CLI、droid、OpenCode 与 Hermes 八家，只读各家本地会话记录里的数字、时间和工作目录，不读对话正文、不联网、不换算金额；同一个仓库的 git worktree 会并到主仓库名下。第一次打开要把历史记录全部读一遍，几 GB 的记录可能要一两分钟，有进度显示，中途关窗下次接着读，之后只读新增部分。
- 配额只在打开这个功能后才取：Claude 与 Pane 底部用量条共用同一条请求时间线，Codex 每 300 秒问一次官方额度（本机 rollout 文件只记录某个会话最后一次响应时的数字，别处用掉的看不到，所以只在 codex 命令找不到时才拿它兜底），Cursor 读它自己的登录凭据问官方用量接口。功能关着时不做任何事。
- 空提示符上直接显示剪贴板里的命令。从别处复制一条命令，切回 Aster 就能看到灰色提示，按回车只把它写进输入行、不执行，确认后再按一次才运行。
- 标签与 Pane 支持双向拖放。标签拖到当前工作区的 Pane 上会整棵并入，靠近哪条边就并到哪一侧；Pane 顶边的胶囊拖到标签栏则变成独立标签。
- 画中画新增「可交互小窗」。系统画中画是视频层，永远不能输入；新的方式把真实终端借进一个置顶小窗，支持完整键盘、输入法与 TUI。在「设置 → 视图 → 画中画」里选。
- 调整窗口或 Pane 大小时，Pane 中央会提示当前的「列 × 行」，停手 0.75 秒后淡出。

## 修复

- 修复中文显示成日文字形。此前只把主字体传给终端引擎，设置里的回退字体完全不生效，汉字用哪个字体由运行时发现决定，可能选中任意已装的等宽 CJK 字体，整段中文变成日文字形，「复」这类字又窄又淡。现在回退字体会一并写进引擎配置。
- 修复 Claude Code 的会话标题要等很久才出现。标题原来只在 Agent 状态翻转时靠全量扫描获取，而提交第一条 prompt 那一刻标题还没写盘，之后又要等下一次翻转，常常到任务结束甚至切换标签后才显示。现在首条 prompt 后几秒内就能出来。
- 修复 Quick Terminal 里输入 `exit` 后窗口不收起。
- 修复托管失败的弹窗里显示调试文本。

## 性能

- 降低 Agent 高速输出时的主线程开销，看不见的终端画面停止绘制，Dock 动画去掉每帧的额外调度，详情面板的端口检查改用系统接口并在窗口不可见时跳过。
- 修复子进程退出后仍要等待孙进程的问题。此前读取子进程输出要等所有写端关闭，而 git 拉起的 fsmonitor、ssh 的 ControlMaster 这类后台进程会长期握住输出端，导致工作线程被长时间占住，累积起来会拖慢并发任务。
