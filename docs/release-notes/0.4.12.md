## Pane 底部用量条

- Claude 用量改为整个 Aster 共享一份数据与一条请求时间线：不管开了多少个 Claude Pane、Agent 启停多少次，对 `/usage` 接口的请求之间都至少隔 90 秒。此前每次 Claude 进程从无到有都会立刻请求一次，多个 Pane 反复启停会把接口打成 429，用量条随之空白；现在新开的 Pane 直接显示共享的上次结果，轮询恢复为每 90 秒一次。

## Agent 会话 resume

- 修复 Claude Code 2.1.x 下 Aster 收不到任何 hook 信号的问题：新版 Claude 启动 hook 时没有控制终端，写 `/dev/tty` 会失败。hook 脚本现在会沿父进程链找到 Pane 的终端设备再写入。此前「会话结束提示 resume 命令并作为同目录补全首选」因此从未生效，现在恢复正常。
- 直接关闭仍在运行 Agent 的 Pane、标签或退出 Aster，也会登记该项目的最近会话，下次在同目录新开终端时补全首选就是对应的 resume 命令。
- Claude Code 与 Codex 的会话关联不再依赖 hook：Aster 直接读取它们写在本机的会话文件，在运行中就把 session ID 绑定到 Pane。标签与标题栏的会话标题、Shell 菜单里的 Fork / 复制会话 ID、结束后的 resume 补全，在没装 hook 或 hook 信号丢失时同样可用。本次运行没有产生新会话文件但目录里有旧会话时，补全首选退化为 `claude --continue` / `codex resume --last`。

## 补全与历史

- 新开 Pane 或命令刚结束时（空 prompt）不再自动弹出候选面板；敲下第一个字符后才自动展开，按 Esc 仍可随时手动打开。行内 ghost（resume 命令、上一条命令的纠错）不受影响。
- 只有真正执行过的命令才进入学习历史：找不到命令（127）、无法执行（126）或输出里明确写 command not found 的命令不再记录，避免打错的词污染后续补全。
