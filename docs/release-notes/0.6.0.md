## 界面语言

- 设置里的“语言”终于起作用了：新增繁體中文、English、日本語、Français、Deutsch 五种界面语言，加上简体中文共六种。菜单、侧栏、窗格提示、对话框、通知和整个设置页都会切换；更改后重新启动 Aster 生效。
- “跟随系统”按 macOS 的偏好语言顺序匹配，`zh-TW` 显示繁体、`en-GB` 显示英文；系统语言不在支持范围时显示英文。
- 终端里程序的输出语言仍由 Shell 自己的 `LANG` 决定，不受此设置影响。

## 受管终端

- 安装包内置了 macOS 版 `aster-session`，本机的受管终端模式开箱可用：分离后任务在后台继续运行，重新附加时进程不变。

## Agent

- 用量条只在确认 Agent 进程真的在运行后才显示，不再因误判而闪现。
- Agent 会话结束时即使没有 Shell 集成也能正确收起用量条与 Agent 绑定。
