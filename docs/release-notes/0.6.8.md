## 新增

- 左侧标签支持标题颜色。默认给每个新标签分配一个互不相同的颜色（12 色调色板，优先挑没被占用的），标签多起来也能一眼定位；颜色随会话快照保存，重启后不变。标签右键菜单新增「标题颜色」：12 个色块、换一个随机颜色、自定义颜色、恢复默认。设置「视图 → 标签页图标与角标 → 随机标题颜色」可以关掉自动着色，你亲手选过的颜色不受影响，继续显示。
- Claude Code 在跑的时候，标签行首的动画改成 Claude Code 自己的星芒：从小圆点长到六芒星再缩回，固定品牌橙，一眼能认出这个 Pane 跑的是哪个 Agent。Codex 保持点阵，其它 Agent 和机器连接状态保持原来的半圆翻转。
- Shell 主动退出后自动关闭所在 Pane。输入 `exit` 或按 Ctrl+D，Pane 直接收掉，不用再点一次关闭；标签里只剩一个 Pane 时关掉整个标签，误关了可以用「重新打开」找回。退出码非零时要求终端至少活过 3 秒才自动关——Shell 一启动就失败会留下画面供排查。信号终止、I/O 失败和受管终端始终保留结束卡，上面的重新附加 / 重新启动入口还在。
- Quick Terminal 可以手动拖尺寸了，四边都有 resize 手柄，最小 320×160。拖出来的尺寸会记住，收起再呼出、重启都保持；改了位置、尺寸百分比或边距会回到百分比基准。新增「快捷终端 → 边距」设置（默认 12 点，0–200），只在不贴屏幕边的那几侧留白：顶部或底部显示时左右留白、贴边那侧仍然贴住，居中显示时四周都留。窗口位置仍然只由设置决定，不能拖走。

## 修复

- 修复 Codex Pane 底部不显示用量条。Codex 的时序是界面先起来、会话 ID 后到，而用量监听只在「界面起来」那一刻检查一次，那时 ID 还是空的，之后就再没有路径重新启动监听。现在 ID 到位会重新同步。
- 修复手动改过窗口大小后，双击标题栏无法放大。AppKit 的窗口尺寸自动保存和放大功能在抢同一份记录，手动拖过尺寸后双击会被判定为「已经放大」而立刻缩回。窗口尺寸本来就以设置里的宽高为准，多出来的那份记录已移除。
- 修复 Shell 退出后偶发崩溃。终端画面释放时如果正好还有一帧待绘制，系统会在已释放的渲染器上重绘并直接崩掉。之前手动关 Pane 慢一步碰不到，配上这版的「退出自动关 Pane」会必现，已在释放前摘掉渲染层。
