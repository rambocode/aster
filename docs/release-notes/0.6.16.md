## 新功能

- **界面文字大小**：「设置 ▸ 外观 ▸ 界面文字」可以调界面字号，共五档，和终端字号互不影响。还有一个「加深界面文字」开关，让侧栏和设置页里偏淡的文字更清楚；系统打开「增强对比度」时自动生效。改字号后需要重启 Aster。
- **Pane 顶边的实时画面按钮**：把鼠标移到终端 Pane 顶边，右上角多了一个眼睛图标，点它收起或恢复实时画面。Claude Code 这类 Agent 接管鼠标后右键菜单弹不出来，这时用它就行。
- **AI 用量统计 Antigravity CLI**：Token 页现在会统计 `agy` 命令行的 token 用量（不含 Antigravity 应用里的会话）。
- **Codex 订阅档位**：配额卡上 Codex 的 Pro 会标出是 Pro 100、Pro 200 还是 Pro 500。
- **原生 SSH 支持 IdentityAgent**：会读取 `~/.ssh/config` 里的 `IdentityAgent`，1Password、Secretive 这类第三方 agent 可以用来认证了。也可以在主机设置的「高级 ▸ Agent 套接字」里单独填。

## 改进

- 放大某个 Pane 后，还原按钮移到窗口标题栏右侧，一直显示。放大期间 Pane 顶边不再出现 `×`、放大按钮和拖动把手。
- 没有键盘焦点的 Pane 不再显示光标，分屏时不会每个 Pane 都留一个空心方框。
- 竖线光标加粗了一点，更容易找到。

## 修复

- 修复设置窗口开着时，点侧栏折叠按钮没有反应的问题。
- 修复界面字号调大后，窗口较小时 Agent 历史、命令面板、全局查找等浮层超出窗口、底部按钮被裁掉的问题。
