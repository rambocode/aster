## 后台托管终端的 Shell 集成

- 由后台会话服务启动的 Shell（本机「本机后台保活」或远程机器上的终端）现在和普通终端一样带有 Aster 的 Shell 集成：提示符标记、命令退出徽标、目录跟踪、别名上报和「下一步」自动补全都能正常工作。此前这些 Shell 完全没有集成，`git clone` 后不会出现 `cd` 提示。
- 远程机器：服务产物现在随附 Shell 集成脚本，「更新远端服务」会一并安装到版本目录里。装好后重启该机器的服务，新启动的 Shell 即生效。

## 修复

- 本机上「远端进程已结束」卡片里的「重新启动 Shell」和「关闭标签」以前点了没有反应。现在「重新启动 Shell」会把这个面板换回普通的本地 Shell，「关闭标签」直接关闭标签。
