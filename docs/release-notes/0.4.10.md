## Quick Terminal

- 新增独立快速终端，通过“窗口 → Quick Terminal”随时呼出或收起。
- 在“设置 → 通用 → Quick Terminal”启用全局快捷键：Control + ` 或 Control + Option + Space。
- 隐藏后保留 Shell、工作目录和滚屏内容；Command + W 只收起快速终端，不会关闭普通工作区标签。
- 支持顶部、底部、左侧、右侧和居中显示，可调整尺寸、显示器、动画时长、失焦隐藏及跟随桌面空间。
- 快捷键冲突时显示提示，仍可通过窗口菜单打开；Shell 结束后可从窗口菜单重新启动。

全局快捷键默认关闭，需要 Aster 保持运行。退出应用会结束快速终端会话，下次启动不恢复该临时会话。
