## Agent 状态检测（无需安装 hook）

- 新增屏幕扫描检测引擎：直接识别终端画面，判断 Agent 正在工作、等待你回答还是已完成。
  即使没有安装 Aster 的 hook 集成，Claude Code、Codex 等也能显示准确状态，尤其是
  「卡在审批 / 提问界面等人」的场景。
- 支持的 Agent 从 8 个扩到 22 个：新增 Gemini CLI、GitHub Copilot CLI、Amp、Droid、
  Devin、Kiro、Qoder、Qwen Code、Hermes、Antigravity、Maki、Muse、Cline、Kilo。
- 已安装 hook 的 Agent 以 hook 为准；当屏幕上出现明确的审批界面而 hook 尚未上报时，
  角标会立即切到「等待输入」。
- 「智能体」设置新增屏幕检测开关；检测规则可用 `~/.config/aster/agent-detection/` 下的
  JSON 文件覆盖，菜单里的「解释 Agent 状态检测…」可查看当前判定依据，便于排查。

## Agent 控制 CLI 与自动化接口

- 新的 `aster` 命令行工具（设置页一键安装）：`aster agent list / prompt / wait`、
  `aster pane read / send-text / wait-output`、`aster events subscribe` 等，Agent 或脚本
  可以读取旁边 Pane 的输出、给另一个 Agent 发任务并等它完成或卡住。
- 每个 Pane 注入 `ASTER_ENV` 与 `ASTER_PANE_ID` 等环境变量；提供可安装到 Claude Code /
  Codex 的 Aster skill，让 Agent 自己学会驾驶 Aster。旧的 `aster open / view / pane` 命令
  全部保持兼容。
- 接口走本机私有 socket，仅当前用户可连；发送按键 / 文本仍受「IPC 允许发送按键」开关
  与敏感会话（ssh / sudo）保护。

## 修复

- 左右分屏分别运行两个 Agent 时，侧栏标签图标与标题胶囊现在跟随当前聚焦的 Pane，
  切换 Pane 即时更新，不再固定显示先启动的那个。
- 修复普通命令（如 `vim agent.py`、`ssh pi`）的窗口标题被误认成 Agent 的问题。
- Claude Code 启动瞬间不再误报一次「任务已完成」。
