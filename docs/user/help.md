# Aster 用户帮助

## Aster 能做什么

Aster 是完全使用 AppKit 构建的原生 macOS 终端工作区。它支持完整彩色终端、`vim`/`top`/`fzf` 等全屏程序、多标签和任意方向分屏，还能把文件浏览器、编辑器与预览放进同一个工作区。

## 开始使用

1. 双击 `Aster.app`，应用会恢复上次工作区；首次启动则在主目录创建登录 Shell。
2. 直接点击终端并输入命令，无需额外输入框。
3. 按 `⌘T` 新建标签，按 `⌘D` 向右拆分，按 `⇧⌘D` 向下拆分；完整分屏命令见“显示”菜单。
4. 按 `⌘K` 打开命令面板，可搜索所有主要动作。

## 标签与三种布局

在“设置 → 外观 → 布局”中选择垂直、顶部或底部。垂直布局默认使用 220pt 窄侧栏，整行标签显示目录名（主目录显示 `~`），切换标签时名字保持不变；有命令正在运行的标签会在行右侧显示旋转指示器；旧版仍使用 250pt 默认值的配置会自动迁移，手动设定的其它宽度不会改变。鼠标移到侧栏上时，顶部右侧会浮现「+」（新建标签页）和折叠图标（隐藏标签栏）；折叠后把鼠标移到窗口顶部（红绿灯右侧）会再次浮现「+」和展开图标，也可通过“显示”菜单的“显示/隐藏标签栏”恢复。新标签默认自动追加，标签面板可保持默认显示或在只有一个标签时隐藏；右键标签可快速分屏、打开文件浏览器或关闭标签。窗口尺寸会在拖动结束后保存，“窗口大小”可恢复默认尺寸。

点击 `TABS` 右侧的整理图标可打开标签菜单：`No Grouping / By Project / By Date` 控制分组，`Created Time / Updated Time` 控制最新标签的排序依据，`Insert Divider` 在当前标签后加入分隔线，`Remove All Dividers` 清除全部手动分隔线。分组和排序选择会自动保存；只有主动选择分组时才显示分组标题。

右键标签并选择“重命名标签页…”可以固定名称，或添加会随运行程序继续更新的动态前缀；“恢复自动标题”重新使用程序发出的 OSC 标题。名称、前缀和最后标题会随工作区恢复。

在“设置 → 外观 → 标签栏”可选择新标签位置：“自动”会把空标签放到当前分组末尾、把带目录或文件的标签放到当前标签后；也可固定为列表末尾或当前标签之后。

窗口失去键盘焦点时，整个工作区会朝主题底色轻微褪色，终端光标同时停止闪烁（形状不变），便于在多窗口之间辨认哪个正在接收输入；重新聚焦即恢复，期间的第一次点击仍会正常落到终端上。终端右侧不再显示会闪现的系统滚动条，滚动历史通过滚轮、键盘和 `⌘F` 查找访问。

主窗口右侧顶部显示活动 Pane 的窗口标题；标签优先显示程序提供的短名称。新建标签、打开文件、分屏、详情和命令面板继续使用菜单或快捷键，不再占用终端上方空间。
Aster 会为 zsh、Bash 和 fish 加载签名的 Shell Integration；支持时，OSC 7 目录会实时同步到侧栏和会话快照，`file://localhost/...` 形式会自动转换为 `~/...` 可读路径，并以本地目录形式安全恢复。

### Shell Integration 与命令导航

- zsh 与 fish 只对 Aster 启动的当前会话注入资源；Bash 和 tmux 子 Shell 使用 `.bashrc`、`.bash_profile`、`.zshrc` 或 fish `conf.d` 中带清晰起止标记的受管区块。Aster 只改动区块本身，保留用户内容、权限和符号链接。
- “设置 → Shell → Shell 集成”默认开启。关闭前会确认并移除受管区块；命令通知、徽标等依赖设置值不会丢失。单个 Shell 可在启动前设置 `ASTER_DISABLE_INTEGRATION=1`。
- `Command+Page Up / Page Down` 跳到上一条或下一条命令；已经被滚动历史裁剪的命令不会跳到错误文本。命令开始时标签显示运行指示器，结束后按设置显示 `✓` 或非零退出码。
- Shell Integration 能确认当前提示符范围时，Backspace 会删除同一输入行内选中的 ASCII 文本；Cut 会先复制再删除。跨行、矩形、Unicode 或命令运行中的选区只复制，不发送可能改错命令的按键。

## 常用目录

Aster 会在本机记录你通过终端访问的目录，并按“使用频率 + 最近时间”维护最多 100 项排名，为后续快速打开和 `jump` 使用。最近一小时访问过的目录权重最高；同一查询会优先匹配完整目录名，再匹配名称前缀、名称包含和完整路径。

“设置 → Shell → 常用目录 → 自动记录访问目录”默认开启；关闭后，新的 OSC 7 目录变化不再写入排名。被加入忽略列表的目录不会因再次 `cd` 自动出现，必须先取消忽略。全部数据只保存在本机，不会上传或自动同步。

## 分屏与 Pane

“显示”菜单集中了全部分屏命令。

**拆分**

- `⌘D` 向右拆分、`⌥⌘D` 向左拆分、`⇧⌘D` 向下拆分、`⌥⇧⌘D` 向上拆分。

**缩放与大小**

- `⇧⌘↩` 缩放拆分：把当前 Pane 临时放大到整个工作区，再按一次还原。放大期间其它 Pane 继续运行，状态栏显示 `ZOOMED`；继续拆分或切换聚焦会自动还原。
- “调整拆分大小”子菜单：`⌃⌘=` 等分拆分，`⌃⌘↑ / ↓ / ← / →` 按 5% 移动当前 Pane 所在的分隔条（方向就是分隔条移动的方向）。
- 分隔条平时是一条灰线，鼠标靠近时会加粗并变成当前主题的强调色；直接拖动即可调整大小，**双击分隔条**恢复等分。比例随会话保存，终端自动收到新的行列尺寸。

**拖动 Pane 重排**

- 把鼠标移到任意 Pane 的顶边中央，会浮现一个灰色小胶囊；指针压上去后胶囊变长、变成主题色，光标切换为抓手。
- 按住胶囊拖动即可搬动整个 Pane，终端进程和滚动历史都不会重启。拖动时落点会高亮：
  - 落在另一个 Pane 的**边缘**（四边各 25%）：用主题色高亮该侧一半区域，松手后 Pane 插到这一侧。
  - 落在另一个 Pane 的**中心**：用绿色高亮整块，松手后两个 Pane 互换位置，分屏结构和比例都不变。
- 拖回自己身上不会有高亮，松手即取消。

**聚焦与关闭**

- “聚焦面板”子菜单：`⌥⌘↑ / ↓ / ← / →` 聚焦相邻 Pane，`⌘]` / `⌘[` 在所有 Pane 之间循环。
- 点击任意 Pane（包括终端内容区）都会把它设为当前 Pane，查找、中断、拆分和关闭都作用于它。分屏时非当前 Pane 会铺一层褪色遮罩，当前 Pane 保持原色，不再画高亮边线；遮罩不拦截点击，点非当前 Pane 的第一下照样落到终端上。
- `⌘W` 关闭当前 Pane；只剩最后一个 Pane 时才关闭整个标签页。`⇧⌘W` 始终关闭整个标签页，`⌥⌘W` 只关闭 Pane。
- 关闭后焦点会落到相邻的 Pane，而不是跳回第一个。

## 文件浏览器、编辑与预览

从“文件 → 打开文件夹”或命令面板打开文件浏览器。双击文件会在相邻 Pane 编辑；右键文件可选择预览或在 Finder 中显示。编辑后标题旁出现 `•`，按 `⌘S` 原子保存。无法读取或保存时，Pane 会显示明确错误，未保存内容不会被清除。

### 打开终端中的文件与链接

按住 `⌘` 点击终端中的目标即可用系统默认应用打开。Aster 能解析绝对路径、`~/`、基于当前 OSC 7 目录的相对路径、`path:line:column`、普通 URL，以及程序发出的 OSC 8 显式链接。

“设置 → 控制 → 文件与链接”可关闭全部目标识别，或把普通文字 URL 限制为 `http`、`https`、`file`、`mailto` 加自定义 scheme。启用识别时，OSC 8 不受自定义 scheme 列表限制，但不会绕过安全检查。

首次打开非标准 scheme（如 `codex://`）时，Aster 会询问“打开一次”“始终允许此 Scheme”或“取消”；可在同一设置区域点击“重置警告”清除例外。可执行文件和 `.app` 应用每次打开都要重新确认，避免同一路径内容被替换后复用旧授权。导入设置不会导入另一台机器的安全授权。为避免阻塞或访问系统设备，FIFO、socket 和设备文件始终拒绝打开。

### 复制与粘贴

- 按 `⌘C`、使用“编辑 → 复制”或终端右键菜单复制选区；按 `⌘V` 粘贴。设置中可开启“选中即复制”“复制时去除行尾空格”和“复制后清除选区”，三项默认均关闭。启用“选中即复制”时会保留高亮以便继续扩展选区，不执行复制后的清除设置。
- 粘贴保护默认开启。内容包含多行、末尾换行、`sudo`/`su` 或不可见控制字符时，Aster 会显示有界预览并要求选择“仍然粘贴”或“取消”。全屏 TUI 或可信 bracketed paste 可跳过普通多行告警，但不可见控制字符始终要求确认；内嵌的 bracketed 结束标记会被转换成可见文本，不能提前执行后续命令。
- “编辑 → 粘贴为”或终端右键“粘贴为”提供：粘贴当前终端选区、选择普通文件并粘贴 Base64、把剪贴板安全转义为单个 POSIX Shell 参数、强制括号粘贴。文件上限为 8 MiB；目录、符号链接、管道、socket、设备和读取期间变化的文件不会被读取。
- “粘贴并在 Composer 中继续”会在 Agent Composer 可用时交接剪贴板文本；未打开 Composer 能力时该右键项置灰。

终端程序可用 OSC 52 请求访问系统剪贴板。“设置 → 控制 → 复制与粘贴”分别提供“允许 / 每次询问 / 拒绝”：写入默认允许，读取默认每次询问。每次询问只授权当前请求，不会记住；连续请求在提示后有 5 秒安全冷却。导入配置不能把读取权限静默改成“允许”；拒绝或超限请求不会读取剪贴板。

### 选择终端文本

- 拖动选择字符，双击选择单词，三击选择整行；按住 `Shift` 点击可从现有锚点扩展。按住 `Option` 拖动会选择矩形列。
- `Shift+← / → / ↑ / ↓` 从光标逐字符或逐行扩展选区；再加 `Option` 切换为矩形选区。`Shift+Command+方向键` 不被 Aster 接管，会继续发送给终端程序。
- vim、tmux 等程序开启鼠标报告时，按住 `Option` 仍可强制使用原生选择，不会把一半鼠标事件发送给程序；`Shift` 是否由程序接收遵循其协商的鼠标模式。
- “设置 → 控制 → 选择”可关闭 Shift 方向键选择，以及配置输入时或显式复制后是否清除高亮。输入时清除默认开启；复制后清除默认关闭。

### 滚动终端历史

- 滚轮或触控板浏览 normal buffer；平滑滚动开启时按像素移动，并在手势结束时对齐字符行。新输出或向终端输入会回到最新内容。
- `Shift+Page Up / Page Down` 向上或向下翻页，`Shift+Home / End` 跳到最早或最新内容；`Command+Page Up / Page Down` 按 Shell 命令跳转。相同命令也位于“显示 → 终端滚动”。
- “设置 → 控制 → 滚动”可关闭平滑滚动，并选择滚过末尾或开头时，把最后内容行、光标行或第一内容行停在视口顶部、中部或底部。全屏 TUI 的 alternate screen 始终禁用越界空白。

### 输入与安全键盘

- 在普通 Shell 提示符中，`⌘←` / `⌘→` 移到行首 / 行尾，`⌥←` / `⌥→` 按词移动；配合 `Delete` 可删除到行首 / 行尾或删除一个词，`⌘Z` 撤销。不同 Shell 没有统一的重做按键，Aster 不发送可能改变命令内容的猜测序列。全屏 TUI 或程序启用 Kitty 键盘协议时，Aster 不替换程序自己的按键编码。
- 新安装默认关闭“Option 作为 Meta”，因此 Option 可继续输入重音和特殊字符；需要 Emacs/Vim 风格 Esc 前缀时可在“设置 → 控制 → 键盘”开启。
- “自动安全输入”默认开启。当前聚焦终端进入 canonical 隐藏输入（例如密码提示）时，Aster 会在输出到达及首个按键发送前启用 macOS Secure Event Input；Vim、less 等 raw-mode TUI 不会误占用。恢复回显、失焦、进程结束或切到其它应用后自动释放。也可从“编辑 → 安全键盘输入”手动开启或关闭；手动状态在 Aster 失活时暂停，切回后恢复。

### Vi、Hint 与只读模式

- 按 `Control+Shift+Space` 或选择“Shell → Vi Mode”进入键盘导航，`Escape` 或 `q` 退出。使用 `h/j/k/l`、方向键、`w/b/e`、`0/$/^`、`H/M/L`、`gg/G`、`Control+U/D/B/F` 移动；动作前可输入次数。`v`、`V`、`Control+V` 分别开始字符、整行和矩形选择，`o` 交换锚点，`y` 或 `Return` 复制并退出。`Command+/` 显示或隐藏按键提示。
- Vi 中按 `/` 或 `?` 打开正向或反向查找，`n` 重复、`N` 反向重复；按 `f` 进入 Hint Mode。也可从 Shell 菜单或 `⌘K` 命令面板直接进入 Mark / Hint。
- Hint Mode 会给当前屏幕内的 URL、OSC 8 链接和文件路径显示短标签。输入标签会按现有安全规则打开目标；让标签最后一键带 `Shift`，则复制规范化 URL 或绝对路径而不打开。按 `Escape` 取消；终端输出改变时旧标签会自动失效。
- “Shell → 只读模式”或 `⌘K` 命令面板按 Pane 切换只读。锁定后键盘、IME、粘贴和 TUI 鼠标报告不会到达程序；输出、滚动、选择、复制和查找仍可用。Vi/Hint 期间只读提示会暂时隐藏，退出后锁仍然有效；编辑器 Pane 也会停止接受修改。关闭并恢复工作区后只读锁不会保留。

### Autocomplete 与 Inline Suggestion

在支持 Shell Integration 的 zsh、Bash 或 fish 提示符中停顿片刻，Aster 会在光标后显示灰色候选。默认按 `Tab` 接受；可在“设置 → 控制 → Autocomplete”改为 `Tab 或 →`、`Control-Space` 或关闭。候选面板默认用 `Escape` 打开：若 inline suggestion 正在显示，第一次 `Escape` 先关闭它，再按一次打开面板。用上下方向键选择，`Return` 或 `Tab` 接受，也可直接点击；面板最多同时显示 8 项。接受候选只补上剩余文字，不会替你按回车执行。

候选来自内置命令/子命令/选项、当前目录文件和文件夹、Shell alias、本机历史、固定命令、README shell code block 和失败纠错。文件名会自动按 Shell 规则转义。Aster 不会自动扫描 `package.json`、Makefile 或 justfile；需要固定项目命令时，先在“设置 → 通用”安装 CLI，然后在目标目录运行：

```bash
aster learn 'npm run deploy'
```

“本机学习”默认开启。学习库只保存脱敏后的命令、目录和计数，不保存输出；`--password`、`--token`、`--api-key` 等值会被移除，退出码 127、明显错误的长选项和“历史忽略模式”匹配项不会保留。没有详细内置结构的命令只会以 `--help`、`-h`、`help` 固定参数在禁网且禁止写入文件的沙箱中探测，并限制为 2.5 秒和 128 KiB；远程会话不会读取本机项目文件或运行本机 help 探测。关闭本机学习后，历史、固定命令、README、纠错与 help 探测全部停用，内置规格和文件补全仍可用。

Fig 命令清单不会后台更新。需要刷新时，在同一设置区域点击“立即更新”；本地 help 规格不会被覆盖。“清除”只删除学习与固定命令，不删除内置或 help 规格。

### Unicode、双向文本与终端图片

- Aster 支持组合字符、CJK 双宽字符、emoji ZWJ/肤色/旗帜序列、text/emoji variation selector，以及 24-bit truecolor、256 色和完整 SGR 样式。圈字母数字默认按两列显示；可在“设置 → 高级 → 加宽 East-Asian-Ambiguous Block”选择其它 block。该宽度策略只影响新建标签和之后写入的字符。
- “设置 → 外观 → 文本”可选择关闭、标准或 discretionary 连字，并设置粗体、斜体与 blink 的渲染策略。blink 默认稳定显示；选择动画后才会闪烁。
- 双向文本默认开启。希伯来文、阿拉伯文和混合方向行按阅读顺序显示，但复制、查找和粘贴仍使用程序写入的逻辑顺序；左右键与鼠标命中跟随视觉位置。遇到自行排版 RTL 的全屏 TUI，可在设置中关闭。程序进入 ECMA-48 mode 8 时 Aster 会自动暂停隐式重排。
- 终端程序可以显示 iTerm2、Kitty 和 Sixel 图片。Aster 会限制输入、分片、解压、像素尺寸与缓存；损坏、取消或超限图片会被丢弃，不影响之后的正常终端输出。

### 任务进度、徽章与通知

终端程序可通过 `OSC 9;4` 报告百分比、不定进度、错误和完成状态；支持 Shell Integration 时，Aster 也会为“设置 → 高级 → 自动进度命令”列表中的常见慢命令自动显示运行状态。列表按空白分词前缀匹配，例如 `git push` 会匹配 `git push origin main`，但不会匹配 `git pushd`；清空列表即可关闭自动匹配。

标签会显示运行、刚完成、未读完成、错误和等待输入状态。等待输入只在 password、`[y/n]`、yes/no 或 Press Enter 提示停留约 1.5 秒后出现，输入任意内容即清除。外观设置可开启 Dock 运行动画；错误标红默认开启，点击 Dock 图标会跳到失败标签并清除当前提示。

安装 `aster` CLI 后，可以包装一次性任务或直接设置当前标签徽章：

```bash
aster watch make deploy
aster watch -q cargo test
aster tab badge --kind awaiting-input
aster tab badge --clear
```

`watch` 保留被包装命令的原退出码；`-q` 只关闭本次完成通知，不关闭进度和徽章。

终端应用可使用 OSC 9、OSC 777 或 OSC 99 发送 macOS 通知。OSC 99 支持独立标题/正文、紧急级别、base64、分片和同 ID 替换。Shell 设置可分别控制：成功、错误与 watch 完成通知，Shell Controlled，总在前台/仅未聚焦标签/关闭的前台策略，Dock 弹跳，错误退出 beep、BEL，以及错误/完成/应用通知是否附带声音。系统权限行显示 macOS 当前状态并可打开系统设置。

标题权限位于“设置 → 高级”：Shell Controlled 控制 OSC 0/1/2 是否能修改标题；“标题报告”控制程序能否读取标题，默认关闭。OSC 52 剪贴板权限与安全键盘输入仍分别位于“控制”。

## 查找与命令面板

按 `⌘F` 在当前终端的完整滚动缓冲区中查找，使用上下箭头跳转。按 `⌘K` 可搜索新建标签、打开文件/文件夹、四个方向的拆分、缩放拆分、等分拆分、聚焦下一个面板、详情面板、Recipes、中断任务和关闭 Pane。

## Recipes 与会话恢复

“工作区”菜单可把当前标签保存成 `.asterrecipe`，或重新打开 Recipe。Recipe 保存标签、分屏、目录和文件，不保存 PID、令牌或文件描述符。外部 Recipe 必须是受大小限制的普通文件，引用的编辑资源也有累计预算。Aster 每次启动会恢复上次可重建的工作区，并启动新的本地 Shell。

误关标签后按 `⇧⌘T` 可按最近关闭顺序逐个恢复。关闭历史跨正常退出和崩溃保留，但恢复时会启动新的运行态，不会复用已经结束的进程。

## 九类设置

设置窗口的侧栏延伸到窗口顶部，左侧导航占满整行并保持左对齐；右侧内容按「分组标题 + 圆角卡片」组织，从页面顶部开始并随窗口宽度伸缩。切换开关或下拉后页面保持当前滚动位置。窗口过小时可以使用右侧滚动条访问完整内容。

- **通用**：界面语言、启动行为、窗口关闭行为、关闭标签页 / 窗口 / 面板的确认策略，以及系统集成（注册为 ssh:// 链接的默认终端、安装 `aster` 命令、Finder「在 Aster 中打开」服务、完全磁盘访问入口）。
- **Shell**：登录 Shell、`TERM`、Shell/SSH 集成、常用目录自动记录、会话恢复、系统通知权限、命令/watch/应用通知、前台策略、通知声音、BEL 和标签徽章。`TERM` 默认填写 `auto`，实际使用兼容的 `xterm-256color`；只有本机存在对应 terminfo 时才采用自定义名称。
- **控制**：Autocomplete / inline suggestion、Option/Meta、TUI 鼠标、焦点跟随鼠标、线性/矩形选择、复制清理、危险粘贴与 bracketed paste、OSC 52 读写权限、文件与链接 scheme/安全例外、平滑及首尾滚动、链接预览与自动安全输入。
- **编辑器**：自动换行、行号、不可见字符、Tab 宽度、滚动越过末尾、Vim 按键与富文档预览。
- **智能体**：启用/停用 Claude Code、Codex、Kimi（附检测状态），标签徽章、通知与运行选项。
- **外观**：标签位置、显示标签栏、Dock 任务状态、浅深色主题、主题编辑/导入、字体、字号、行高、侧栏和光标。
- **Recipes**：命令重放模式与安全边界；不自动执行外部 Recipe 中的命令。
- **快捷键**：查看内置快捷键。
- **高级**：自动进度命令、标题修改/读取权限、导入/导出 JSON 配置、重置和运行内核信息。

设置会随配置一同保存与导出；通知最终是否显示还取决于 macOS“系统设置 → 通知”中的应用权限和横幅样式。

## 常见问题

### `vim` 或 `top` 显示不正常？

确认“设置 → Shell → 终端类型”为 `auto`（或本机真实安装的 terminfo 名称），并开启“控制 → 允许鼠标报告”。无效的自定义名称会在 Pane 中显示启动告警并自动回退到 `xterm-256color`。

### 输入 `exit` 后怎么办？

该 Pane 会保留历史但标记为结束。关闭 Pane，或新建标签/分屏即可启动新 Shell。

### Recipe 会自动执行命令吗？

当前版本不会执行导入 Recipe 中的命令，只恢复经校验的工作区布局；命令字段仅为未来兼容预留，避免打开外部文件时发生意外执行。

### 关闭编辑器时会丢内容吗？

不会直接丢弃。存在未保存内容时，关闭 Pane、标签或退出应用都会询问“保存 / 不保存 / 取消”；保存失败会阻止关闭。

## 外观主题

### 选择主题

打开“设置 → 外观”，在主题卡片中选择预设。Aster 内置与 Otty 1.3.1 对齐的 9 个浅色主题和 15 个深色主题；选择后，设置页、工作区和已经打开的终端会立即更新。开启“深色模式使用独立主题”后，可以分别选择浅色与深色主题。

Glass Light 与 Glass Dark 会使用原生材质和主题表面色呈现透明视觉，不会再出现错误黑底；Floating Card、Nord、Pink、Monokai Classic 等主题会同时使用各自的光标文字色和选区前景/背景，不再用通用近似色替代。

### 创建和编辑主题

1. 选中一个主题并查看“详情”中的终端、界面角色色和 ANSI 16 色预览。
2. 点击“复制”创建可编辑副本；内置主题不会被覆盖。
3. 点击“编辑当前主题”，修改名称、明暗模式、窗口/容器/面板颜色、文字、强调色、光标、选区及 ANSI 颜色。
4. 点击颜色块调用系统取色器；点击“保存”后同时写入应用配置和主题文件夹，取消则放弃草稿。

主题名称不能与现有主题重复。编辑失败时，Aster 会保留草稿并显示原因。

### 导入主题

点击“导入主题…”选择 `.astertheme` 文件。Aster 只接受 256 KiB 以内的普通文件，并在加入主题库前检查名称和完整的 ANSI 16 色。点击“打开主题文件夹”可以查看复制、编辑和导入后的文件。

### 字体与光标

“文本”区域可以实时调整字号和基础等宽字体；粗体与斜体由可用字体自动匹配。“光标”区域提供方块、竖线、下划线和空心方块，以及闪烁开关。这里选定的形状是唯一真值：Claude Code、vim 等终端程序请求切换光标形状时会被忽略，光标始终保持你设置的样子。
