# Aster 用户帮助

## Aster 能做什么

Aster 是完全使用 AppKit 构建的原生 macOS 终端工作区。它支持完整彩色终端、`vim`/`top`/`fzf` 等全屏程序、多标签和任意方向分屏，还能把文件浏览器、编辑器与预览放进同一个工作区。

## 诊断日志与反馈

从“帮助 → 反馈问题…”可以填写可选的问题描述，再选择“保存诊断包…”或“分享…”。Aster 会在你点击操作后生成 ZIP，并交给 macOS 的系统分享面板；不会自动上传任何信息。诊断包只包含最近 7 天、最多 20 MB 的 Aster 应用日志、版本和系统摘要，不包含终端输入输出、命令、路径、环境变量、配置、剪贴板或系统崩溃报告。你也可以在该页点“打开日志文件夹”先自行查看本机日志。

## 开始使用

1. 双击 `Aster.app`，应用会恢复上次工作区；首次启动则在主目录创建登录 Shell。
2. 直接点击终端并输入命令，无需额外输入框。
3. 按 `⌘T` 新建标签，按 `⌘D` 向右拆分，按 `⇧⌘D` 向下拆分；完整分屏命令见“显示”菜单。
4. 按 `⌘K` 打开命令面板，可搜索所有主要动作。

### 多窗口、置顶与画中画

- 按 `⌘N` 新建独立工作区窗口；每个窗口拥有自己的标签、分屏和恢复快照。正常退出后会恢复仍打开的附加窗口，主动关闭的窗口不会在下次启动重新出现。
- 拖动垂直或水平标签到另一个 Aster 窗口可移动标签；拖到所有窗口之外会创建新窗口。该操作保留正在运行的 PTY、滚动历史、编辑草稿和 Agent 状态。
- “显示 → Pin Window”切换当前工作区置顶；独立设置窗口不会改变置顶状态。“Picture in Picture”可固定当前 Pane，或让浮动面板跟随活动 Pane。

## 标签与三种布局

在“设置 → 外观 → 布局”中选择垂直、顶部或底部。垂直布局默认使用 220pt 窄侧栏。拖动左栏与中央内容之间的分隔线可在 180...360pt 内调宽；分隔线悬停时会变成强调色，双击恢复 220pt。拖动只调整宽度，不会折叠侧栏。整行标签显示目录名（主目录显示 `~`），切换标签时名字保持不变；有命令正在运行的标签会在行右侧显示旋转指示器，鼠标移到标签行时该位置换成 `×`，点击可直接关闭该标签，关闭后台标签不会先切换过去。旧版侧栏宽度会在该工作区窗口首次建立 Panel 布局时迁移；之后每个工作区窗口独立保存自己的左右宽度。标签行显示为左右留边的圆角卡片，选中和鼠标悬停都会给卡片加底色。鼠标移到侧栏任意位置时，顶部右侧会浮现「+」（新建标签页）；把鼠标再往上移到红绿灯那一行，旁边会额外浮现折叠图标（隐藏标签栏）。点击标签切换时「+」保持显示，不会闪一下消失；折叠后把鼠标移到窗口顶部（红绿灯右侧）会再次浮现「+」和展开图标，也可通过“显示”菜单的“显示/隐藏标签栏”恢复。新标签默认自动追加，标签面板可保持默认显示或在只有一个标签时隐藏；右键标签可快速分屏、打开文件浏览器或关闭标签。终端内容直接延伸到窗口底部，不再显示 `workspace · 路径 / PANE / UTF-8` 状态栏。窗口尺寸会在拖动结束后保存，“窗口大小”可恢复默认尺寸。

点击 `TABS` 右侧的整理图标可打开标签菜单：`No Grouping / By Project / By Date` 控制分组，`Created Time / Updated Time` 控制最新标签的排序依据，`Insert Divider` 在当前标签后加入分隔线，`Remove All Dividers` 清除全部手动分隔线。分组和排序选择会自动保存；只有主动选择分组时才显示分组标题。

右键标签并选择“重命名标签页…”可以固定名称，或添加会随运行程序继续更新的动态前缀；“恢复自动标题”重新使用程序发出的 OSC 标题。名称、前缀和最后标题会随工作区恢复。

在“设置 → 外观 → 标签栏”可选择新标签位置：“自动”会把空标签放到当前分组末尾、把带目录或文件的标签放到当前标签后；也可固定为列表末尾或当前标签之后。

窗口失去键盘焦点时，整个工作区会朝主题底色轻微褪色，终端光标同时停止闪烁（形状不变），便于在多窗口之间辨认哪个正在接收输入；重新聚焦即恢复，期间的第一次点击仍会正常落到终端上。终端右侧不再显示会闪现的系统滚动条，滚动历史通过滚轮、键盘和 `⌘F` 查找访问。

主窗口右侧顶部与终端画布使用完全相同的背景色，普通状态显示活动 Pane 的程序标题。把鼠标移到标题上会显示当前工作目录的灰色路径胶囊；点击后可直接设置标签名称/前缀、复制路径、在 Finder 或已安装编辑器中打开、预填 Git 命令、分屏，以及打开当前查找、全局查找、Jump to 和命令面板。“Notifications & Privileges”会跳到 Shell 通知设置。Git 写操作只预填到终端，仍由你回车确认。
Aster 会为 zsh、Bash 和 fish 加载签名的 Shell Integration；支持时，OSC 7 目录会实时同步到侧栏和会话快照，`file://localhost/...` 形式会自动转换为 `~/...` 可读路径，并以本地目录形式安全恢复。

### Shell Integration 与命令导航

- zsh 与 fish 只对 Aster 启动的当前会话注入资源；Bash 和 tmux 子 Shell 使用 `.bashrc`、`.bash_profile`、`.zshrc` 或 fish `conf.d` 中带清晰起止标记的受管区块。Aster 只改动区块本身，保留用户内容、权限和符号链接。
- “设置 → Shell → Shell 集成”默认开启。关闭前会确认并移除受管区块；命令通知、徽标等依赖设置值不会丢失。单个 Shell 可在启动前设置 `ASTER_DISABLE_INTEGRATION=1`。
- `Command+Page Up / Page Down` 跳到上一条或下一条命令；已经被滚动历史裁剪的命令不会跳到错误文本。命令开始时标签显示运行指示器，结束后按设置显示 `✓` 或非零退出码。
- Shell Integration 能确认当前提示符范围时，Backspace 会删除同一输入行内选中的 ASCII 文本；Cut 会先复制再删除。跨行、矩形、Unicode 或命令运行中的选区只复制，不发送可能改错命令的按键。

## 常用目录

Aster 会在本机记录你通过终端访问的目录，并按“使用频率 + 最近时间”维护最多 100 项排名，为后续快速打开和 `jump` 使用。最近一小时访问过的目录权重最高；同一查询会优先匹配完整目录名，再匹配名称前缀、名称包含和完整路径。

“设置 → Shell → 常用目录 → 自动记录访问目录”默认开启；关闭后，新的 OSC 7 目录变化不再写入排名。被加入忽略列表的目录不会因再次 `cd` 自动出现，必须先取消忽略。全部数据只保存在本机，不会上传或自动同步。

## 分屏与 Pane

“显示”菜单集中了全部分屏命令。

**拆分**

- `⌘D` 向右拆分、`⌥⌘D` 向左拆分、`⇧⌘D` 向下拆分、`⌥⇧⌘D` 向上拆分。

**缩放与大小**

- `⇧⌘↩` 缩放拆分：把当前 Pane 临时放大到整个工作区，再按一次还原。放大期间其它 Pane 继续运行；继续拆分或切换聚焦会自动还原。
- “调整拆分大小”子菜单：`⌃⌘=` 等分拆分，`⌃⌘↑ / ↓ / ← / →` 按 5% 移动当前 Pane 所在的分隔条（方向就是分隔条移动的方向）。
- 分隔条平时是一条灰线，鼠标靠近时会加粗并变成当前主题的强调色；直接拖动即可调整大小，**双击分隔条**恢复等分。比例随会话保存，终端自动收到新的行列尺寸。

**拖动 Pane 重排**

- 把鼠标移到任意 Pane 的顶边中央，会浮现一个灰色小胶囊；指针压上去后胶囊变长、变成主题色，光标切换为抓手。
- 按住胶囊拖动即可搬动整个 Pane，终端进程和滚动历史都不会重启。拖动时落点会高亮：
  - 落在另一个 Pane 的**边缘**（四边各 25%）：用主题色高亮该侧一半区域，松手后 Pane 插到这一侧。
  - 落在另一个 Pane 的**中心**：用绿色高亮整块，松手后两个 Pane 互换位置，分屏结构和比例都不变。
- 拖回自己身上不会有高亮，松手即取消。

**聚焦与关闭**

- “聚焦面板”子菜单：`⌥⌘↑ / ↓ / ← / →` 聚焦相邻 Pane，`⌘]` / `⌘[` 在所有 Pane 之间循环。
- 点击任意 Pane（包括终端内容区）都会把它设为当前 Pane，查找、中断、拆分和关闭都作用于它。分屏时非当前 Pane 会铺一层褪色遮罩，当前 Pane 保持原色，不再画高亮边线；遮罩不拦截点击，点非当前 Pane 的第一下照样落到终端上。
- `⌘W` 关闭当前 Pane；只剩最后一个 Pane 时才关闭整个标签页。`⇧⌘W` 始终关闭整个标签页，`⌥⌘W` 只关闭 Pane。
- 关闭后焦点会落到相邻的 Pane，而不是跳回第一个。

## 文件浏览器、编辑与预览

详情面板的 Files 页以当前工作目录为根。双击 Markdown、reStructuredText、HTML、SVG 或普通源码会在右侧以可编辑 Source 打开；图片、PDF、富文档、diff、Agent transcript 和二进制保持只读预览。目录用箭头或双击在树内展开。右键菜单包含：

- `Open`：使用 macOS 默认应用；可执行文件或 `.app` 会再次确认。
- `Open in Aster`：可选 Current Pane、New Tab、New Window、Split Right/Left/Top/Bottom。
- `New File…` / `New Folder…`：文件选中时创建在其父目录，目录选中时创建在目录内部；不会覆盖同名项。新文件会在右侧以可编辑 Source 打开。
- `Rename…` / `Move to Trash`：重命名后已打开 Pane 会继续跟踪新路径；删除进入系统废纸篓，可以恢复。
- `Copy Path` / `Copy Relative Path` / `Reveal in Finder`：相对路径以当前 Files 根目录为准且不带 `./`。

File Pane 顶部左侧提供模式胶囊、发送到 Chat 和共享；中间显示文件名与更多菜单；右侧显示 `✓ Saved`、`Edited`、磁盘冲突或错误，并提供保存和关闭。Markdown、reStructuredText、HTML 与 SVG 使用 code/eye 在可编辑 Source 和 Preview 间切换；普通源码使用 code/lock 就地锁定或解锁。切换会保留源码选区、滚动位置和撤销记录；`⌘S` 原子保存，不会自动保存。存在未保存内容时关闭仍会询问保存、放弃或取消。外部程序修改文件时，未编辑的 Pane 自动重载；本地已有修改时显示 `Modified on Disk`，可从 `… → Reload from Disk` 明确放弃本地内容。

Preview 支持 Markdown（含 GFM 表格、任务列表等）、reStructuredText、HTML、SVG、常见图片/GIF、PDF、diff、Office/媒体/字体 Quick Look、二进制 hex 和 Aster 已识别的 Agent transcript。HTML/SVG/Markdown 预览禁用 JavaScript 与网络请求；Agent transcript 可 Resume 或 Fork。二进制 hex 只按可见行绘制，超大文本和二进制只读取有界内容，避免单个 Pane 占满内存。远程 SSH 路径暂不支持 File Pane。

普通 UTF-8 文件可从 File Pane 点气泡图标“发送到 Chat”；文件必须是非符号链接且不超过 64 KiB，内容会先移除控制字符并遮盖常见 secret。无法读取或保存时，Pane 会显示明确错误，未保存内容不会被清除。

把 Finder 文件或目录拖到 Pane 边缘，可按高亮方向创建预览、文件浏览器或继承目录的新终端；把纯文本拖到终端会经过与粘贴相同的危险内容确认。HTTP/HTTPS URL 会交给默认浏览器。一次最多处理 32 个 URL，符号链接和特殊文件不会被读取。

### 打开终端中的文件与链接

按住 `⌘` 点击终端中的目标即可用系统默认应用打开。Aster 能解析绝对路径、`~/`、基于当前 OSC 7 目录的相对路径、`path:line:column`、普通 URL，以及程序发出的 OSC 8 显式链接。

“设置 → 控制 → 文件与链接”可关闭全部目标识别，或把普通文字 URL 限制为 `http`、`https`、`file`、`mailto` 加自定义 scheme。启用识别时，OSC 8 不受自定义 scheme 列表限制，但不会绕过安全检查。

首次打开非标准 scheme（如 `codex://`）时，Aster 会询问“打开一次”“始终允许此 Scheme”或“取消”；可在同一设置区域点击“重置警告”清除例外。可执行文件和 `.app` 应用每次打开都要重新确认，避免同一路径内容被替换后复用旧授权。导入设置不会导入另一台机器的安全授权。为避免阻塞或访问系统设备，FIFO、socket 和设备文件始终拒绝打开。

### 复制与粘贴

- 按 `⌘C`、使用“编辑 → 复制”或终端右键菜单复制选区；按 `⌘V` 粘贴。设置中可开启“选中即复制”“复制时去除行尾空格”和“复制后清除选区”，三项默认均关闭。启用“选中即复制”时会保留高亮以便继续扩展选区，不执行复制后的清除设置。
- 粘贴保护默认开启。内容包含多行、末尾换行、`sudo`/`su` 或不可见控制字符时，Aster 会显示有界预览并要求选择“仍然粘贴”或“取消”。全屏 TUI 或可信 bracketed paste 可跳过普通多行告警，但不可见控制字符始终要求确认；内嵌的 bracketed 结束标记会被转换成可见文本，不能提前执行后续命令。
- “编辑 → 粘贴为”或终端右键“粘贴为”提供：粘贴当前终端选区、选择普通文件并粘贴 Base64、把剪贴板安全转义为单个 POSIX Shell 参数、强制括号粘贴。文件上限为 8 MiB；目录、符号链接、管道、socket、设备和读取期间变化的文件不会被读取。
- “粘贴并在 Composer 中继续”会在 Agent Composer 可用时交接剪贴板文本；未打开 Composer 能力时该右键项置灰。
- “编辑 → Prompt 队列…”在当前终端 Pane 中可用，不会因 Claude Code 或 Codex 的识别状态变化而置灰。它在 Pane 底部打开输入条；按 Return 或右下角上箭头把内容加入上方列表。已在设置里安装 lifecycle hook 的 Claude Code / Codex，队列会自动发送：Agent 空闲（等你输入下一条）时立刻发出队首，正在执行时先排队、等这一轮结束再发，并且一次只发一条。等待权限确认（awaiting-input）时不会自动发送 —— 那时屏幕上是确认选择器，替你回车等于批准了一次工具调用。没有安装 hook 的普通 CLI 保持全手动。
- 任何时候都可以点击某项左侧的 ↳ 图标立即插队提交，右侧垃圾桶可移除尚未发送的项。关闭输入条不会取消队列，展开按钮可输入多行，队列仍受只读和终端输入模式限制。
- “编辑 → 发送到聊天…”以及终端右键“发送选区到 Chat”会打开确认面板。可同时选择当前选区与当前终端 transcript，并从当前工作区所有运行中的 Claude Code/Codex Pane 选择接收端；点击 Send 会以普通键入预填 Comment 和清理、脱敏后的上下文，不会自动回车。

终端程序可用 OSC 52 请求访问系统剪贴板。“设置 → 控制 → 复制与粘贴”分别提供“允许 / 每次询问 / 拒绝”：写入默认允许，读取默认每次询问。每次询问只授权当前请求，不会记住；连续请求在提示后有 5 秒安全冷却。导入配置不能把读取权限静默改成“允许”；拒绝或超限请求不会读取剪贴板。

### 选择终端文本

- 拖动选择字符，双击选择单词，三击选择整行；按住 `Shift` 点击可从现有锚点扩展。按住 `Option` 拖动会选择矩形列。
- `Shift+← / → / ↑ / ↓` 从光标逐字符或逐行扩展选区；再加 `Option` 切换为矩形选区。`Shift+Command+方向键` 不被 Aster 接管，会继续发送给终端程序。
- vim、tmux 等程序开启鼠标报告时，按住 `Option` 仍可强制使用原生选择，不会把一半鼠标事件发送给程序；`Shift` 是否由程序接收遵循其协商的鼠标模式。
- “设置 → 控制 → 选择”可关闭 Shift 方向键选择，以及配置输入时或显式复制后是否清除高亮。输入时清除默认开启；复制后清除默认关闭。

### 滚动终端历史

- 滚轮或触控板浏览 normal buffer；平滑滚动开启时按像素移动，并在手势结束时对齐字符行。新输出或向终端输入会回到最新内容。
- `Shift+Page Up / Page Down` 向上或向下翻页，`Shift+Home / End` 跳到最早或最新内容；`Command+Page Up / Page Down` 按 Shell 命令跳转。相同命令也位于“显示 → 终端滚动”。
- “设置 → 控制 → 滚动”可关闭平滑滚动，并选择滚过末尾或开头时，把最后内容行、光标行或第一内容行停在视口顶部、中部或底部。全屏 TUI 的 alternate screen 始终禁用越界空白。

### 渲染与持续输出

Aster 会在终端进入窗口后自动使用 macOS Metal 渲染，只重建发生变化的可见行；短提示和
按键回显优先低延迟交付，持续大量输出按有界批次处理，期间仍会给鼠标、键盘和面板操作
留出主线程机会。GPU 或渲染资源不可用时会自动回退到 Core Graphics，不影响 Shell、
滚动历史和终端内容，也不需要手动切换设置。

### 输入与安全键盘

- 在普通 Shell 提示符中，`⌘←` / `⌘→` 移到行首 / 行尾，`⌥←` / `⌥→` 按词移动；配合 `Delete` 可删除到行首 / 行尾或删除一个词，`⌘Z` 撤销。不同 Shell 没有统一的重做按键，Aster 不发送可能改变命令内容的猜测序列。全屏 TUI 或程序启用 Kitty 键盘协议时，Aster 不替换程序自己的按键编码。
- “编辑 → 插入”可选择一个或多个文件/文件夹路径，或调用系统交互式截屏；结果会以安全转义后的路径预填到当前前台程序的输入框（包括 Codex/Claude 等 TUI），但不会自动执行。“编辑 → Insert from iPhone”会显示附近可用的 iPhone/iPad 拍照或扫描入口，完成后通过同一入口插入私有临时文件路径。手机导入只接受常见图片或 PDF，单项最大 32 MiB。
- “编辑 → 编辑器”（`⇧⌘E`）会选择一个本地文件，并在当前 Pane 右侧打开可编辑 Pane；“Prompt 队列…”（`⇧⌘M`）和“发送到聊天…”分别打开当前终端的队列输入条与发送确认面板。
- 新安装默认关闭“Option 作为 Meta”，因此 Option 可继续输入重音和特殊字符；需要 Emacs/Vim 风格 Esc 前缀时可在“设置 → 控制 → 键盘”开启。
- “自动安全输入”默认开启。当前聚焦终端进入 canonical 隐藏输入（例如密码提示）时，Aster 会在输出到达及首个按键发送前启用 macOS Secure Event Input；Vim、less 等 raw-mode TUI 不会误占用。恢复回显、失焦、进程结束或切到其它应用后自动释放。也可从“编辑 → 安全键盘输入”手动开启或关闭；系统保护真实生效后，主工作区标题栏右侧显示蓝色 `SECURE INPUT` 胶囊。手动状态在 Aster 失活时暂停，切回后恢复。
- Codex、Claude 和普通 Shell 输入框保留 `Ctrl+A`、`Ctrl+E`、`Ctrl+K`、`Ctrl+U`、`Ctrl+W` 等常用行编辑控制键；Aster 的 `⌘←`、`⌥←` 等原生菜单快捷键不会占用这些组合。

### 字号与全屏

- 在“显示”菜单选择“增大字号”“减小字号”或“重置字号”，也可使用 `⌘=`、`⌘-`、`⌘0`。字号范围为 9–32pt，重置值为 13pt，并会同步应用到所有已打开终端。
- 选择“显示 → 进入全屏幕”或按 `Fn+F` 切换当前工作区窗口；进入后同一菜单项会显示为“退出全屏幕”。

### Vi、Hint 与只读模式

- 按 `Control+Shift+Space` 或选择“Shell → Vi Mode”进入键盘导航，`Escape` 或 `q` 退出。使用 `h/j/k/l`、方向键、`w/b/e`、`0/$/^`、`H/M/L`、`gg/G`、`Control+U/D/B/F` 移动；动作前可输入次数。`v`、`V`、`Control+V` 分别开始字符、整行和矩形选择，`o` 交换锚点，`y` 或 `Return` 复制并退出。`Command+/` 显示或隐藏按键提示。
- Vi 中按 `/` 或 `?` 打开正向或反向查找，`n` 重复、`N` 反向重复；按 `f` 进入 Hint Mode。也可从 Shell 菜单或 `⌘K` 命令面板直接进入 Mark / Hint。
- Hint Mode 会给当前屏幕内的 URL、OSC 8 链接和文件路径显示短标签。输入标签会按现有安全规则打开目标；让标签最后一键带 `Shift`，则复制规范化 URL 或绝对路径而不打开。按 `Escape` 取消；终端输出改变时旧标签会自动失效。
- “Shell → 只读模式”或 `⌘K` 命令面板按 Pane 切换只读。锁定后键盘、IME、粘贴和 TUI 鼠标报告不会到达程序；输出、滚动、选择、复制和查找仍可用。Vi/Hint 期间只读提示会暂时隐藏，退出后锁仍然有效；编辑器 Pane 也会停止接受修改。关闭并恢复工作区后只读锁不会保留。

### Autocomplete 与 Inline Suggestion

在支持 Shell Integration 的 zsh、Bash 或 fish 提示符中停顿片刻，Aster 会在 Shell 完成本次输入回显后，于最新光标位置显示灰色候选。继续输入时，上一轮候选会立刻隐藏，等新候选准备好再显示，因此不会覆盖正在输入的命令。默认按 `Tab` 接受；可在“设置 → 控制 → Autocomplete”改为 `Tab 或 →`、`Control-Space` 或关闭。候选面板默认用 `Escape` 打开：若 inline suggestion 正在显示，第一次 `Escape` 先关闭它，再按一次打开面板。用上下方向键选择，`Return` 或 `Tab` 接受，也可直接点击；面板最多同时显示 8 项。接受候选只补上剩余文字，不会替你按回车执行。

候选来自内置命令/子命令/选项、当前目录文件和文件夹、Shell alias、本机历史、固定命令、README shell code block 和失败纠错。文件名会自动按 Shell 规则转义。Aster 不会自动扫描 `package.json`、Makefile 或 justfile；需要固定项目命令时，先在“设置 → 通用”安装 CLI，然后在目标目录运行：

```bash
aster learn 'npm run deploy'
```

“本机学习”默认开启。学习库只保存脱敏后的命令、目录和计数，不保存输出；`--password`、`--token`、`--api-key` 等值会被移除，退出码 127、明显错误的长选项和“历史忽略模式”匹配项不会保留。没有详细内置结构的命令只会以 `--help`、`-h`、`help` 固定参数在禁网且禁止写入文件的沙箱中探测，并限制为 2.5 秒和 128 KiB；远程会话不会读取本机项目文件或运行本机 help 探测。关闭本机学习后，历史、固定命令、README、纠错与 help 探测全部停用，内置规格和文件补全仍可用。

Fig 命令清单不会后台更新。需要刷新时，在同一设置区域点击“立即更新”；本地 help 规格不会被覆盖。“清除”只删除学习与固定命令，不删除内置或 help 规格。

### Unicode、双向文本与终端图片

- Aster 支持组合字符、CJK 双宽字符、emoji ZWJ/肤色/旗帜序列、text/emoji variation selector，以及 24-bit truecolor、256 色和完整 SGR 样式。圈字母数字默认按两列显示；可在“设置 → 高级 → 加宽 East-Asian-Ambiguous Block”选择其它 block。该宽度策略只影响新建标签和之后写入的字符。
- “设置 → 外观 → 文本”可选择关闭、标准或 discretionary 连字，并设置粗体、斜体与 blink 的渲染策略。blink 默认稳定显示；选择动画后才会闪烁。
- 双向文本默认开启。希伯来文、阿拉伯文和混合方向行按阅读顺序显示，但复制、查找和粘贴仍使用程序写入的逻辑顺序；左右键与鼠标命中跟随视觉位置。遇到自行排版 RTL 的全屏 TUI，可在设置中关闭。程序进入 ECMA-48 mode 8 时 Aster 会自动暂停隐式重排。
- 终端程序可以显示 iTerm2、Kitty 和 Sixel 图片。Aster 会限制输入、分片、解压、像素尺寸与缓存；损坏、取消或超限图片会被丢弃，不影响之后的正常终端输出。
- 应用包内置 Aster Nerd Symbols fallback；即使基础字体没有 Powerline 或 Nerd Font 图标，终端仍能解析 BMP 与补充平面符号。基础正文继续使用你在“设置 → 外观”选择的字体。

### 任务进度、徽章与通知

终端程序可通过 `OSC 9;4` 报告百分比、不定进度、错误和完成状态；支持 Shell Integration 时，Aster 也会为“设置 → 高级 → 自动进度命令”列表中的常见慢命令自动显示运行状态。列表按空白分词前缀匹配，例如 `git push` 会匹配 `git push origin main`，但不会匹配 `git pushd`；清空列表即可关闭自动匹配。

标签会在名称右侧显示运行、刚完成、未读完成、错误和等待输入状态；Agent 在处理、请求确认、恢复处理和完成之间切换时，图标会就地变化，不会重建终端或打断输入。等待输入只在 password、`[y/n]`、yes/no 或 Press Enter 提示停留约 1.5 秒后出现，输入任意内容即清除；Agent 完成后的未读圆点也会在用户继续输入后清除。外观设置可开启 Dock 运行动画；错误标红默认开启，点击 Dock 图标会跳到失败标签并清除当前提示。

安装 `aster` CLI 后，可以包装一次性任务或直接设置当前标签徽章：

```bash
aster watch make deploy
aster watch -q cargo test
aster tab badge --kind awaiting-input
aster tab badge --clear
```

`watch` 保留被包装命令的原退出码；`-q` 只关闭本次完成通知，不关闭进度和徽章。

终端应用可使用 OSC 9、OSC 777 或 OSC 99 发送 macOS 通知。OSC 99 支持独立标题/正文、紧急级别、base64、分片和同 ID 替换。Shell 设置可分别控制：成功、错误与 watch 完成通知，Shell Controlled，总在前台/仅未聚焦标签/关闭的前台策略，Dock 弹跳，错误退出 beep、BEL，以及错误/完成/应用通知是否附带声音。系统权限行显示 macOS 当前状态并可打开系统设置。

标题权限位于“设置 → 高级”：Shell Controlled 控制 OSC 0/1/2 是否能修改标题；“标题报告”控制程序能否读取标题，默认关闭。OSC 52 剪贴板权限与安全键盘输入仍分别位于“控制”。

## 查找与命令面板

按 `⌘F` 在当前终端的完整滚动缓冲区中查找，可切换大小写和正则表达式并用上下箭头跳转。“全局查找”会同时搜索所有终端、编辑器与预览 Pane，并跳回对应标签、Pane 和行。

按 `⇧⌘O` 打开 Open Quickly，顶部标签条可在“全部 / 已打开 / 最近 / 文件夹 / SSH / Agents / 当前 / Recipes”中过滤（`⌘J` 直接打开“当前”页）；支持模糊搜索，结果行带类型图标、相对时间和类型徽章，多类型视图按分组显示小节标题。结果会直接跳到 Pane、打开常用目录、预填 SSH、恢复 Agent 历史或打开 Recipe。“当前”页还会显示各 Pane 正在运行的前台命令；若有 Pane 正在运行 Agent，会追加“提示词”分组列出该会话最近的输入，点击即粘贴回该 Pane 的输入行（不自动回车）。列表内用 `↑`/`↓` 选择、`↩` 跳转、`⌘1`–`⌘9` 快速选中对应行，`⌘K` 或底部“操作”按钮弹出选中行的更多动作（关闭标签、Fork 会话、在 Finder 中显示、复制提示词等）。按住 `⌘` 会在顶部标签和前九条结果上显示快捷键：`⌘0/W/R/Z/S/G/J/E` 分别切换全部、已打开、最近、文件夹、SSH、智能体、当前和 Recipes，松开后提示自动隐藏。按 `Esc`、切换到其他应用，或在 Aster 窗口的浮层外部（包括标题栏）用任意鼠标键点击，都会立即关闭面板。按 `⇧⌘P` 打开的命令面板还覆盖新窗口、Pin、两种画中画、详情、Agent、分屏、文件、查找、模式与关闭动作，并标明 Pane / Window / App 作用域。

Open Quickly 打开后输入焦点会直接落在搜索框，无需再点击即可输入；点击搜索框也不会触发外部点击关闭。Open Quickly 中的 Agents 分类在界面显示为“智能体”。浮层打开、关闭和顶部分类切换不会重建终端工作区；结果较多时仍可直接输入搜索，既有结果行会复用，避免点击时出现明显停顿。

“显示 → 详情面板”包含 Info、Outline、Git 和 Files 四页，顶部 icon 页签切换：未选中页签保持统一的图标宽度与间距，鼠标悬停会有淡底色反馈，点击后当前页签平滑展开出名称（系统开启“减弱动态效果”时直接切换）。详情面板展开时，右上角折叠图标一直显示；面板收起后，同一位置的标题栏展开图标只在鼠标位于标题栏时显示。为了让关闭动作更自然，收起完成时图标会在原位短暂停留，再在鼠标已离开标题栏时淡出，整个过程不会左右跳动或闪出第二颗图标。也可通过“显示”菜单或命令面板切换。拖动中央内容与详情面板之间的分隔线可在 240...480pt 内调宽，双击恢复默认 278pt；拖动不会收起详情面板。展开与收起带 0.18 秒的整块折叠/展开过渡（系统开启“减弱动态效果”时直接切换）：详情内容由 Panel 边界同步裁剪，中央区域同时补位，不会先滑走内容再折叠空壳；终端只在显隐终态切换时调整一次。展开、收起和页签切换不会重建终端、侧栏或已经加载的页面，终端输入焦点保持不变；收起时会停止尚未完成的检查，但保留已完成结果与 Files 的搜索、排序和展开状态。Info 页显示工作目录、动作链接（复制路径、在 Finder 显示、在已安装的编辑器中打开）、以当前 shell 为根的本机进程树与去重监听端口；只有 lifecycle 集成精确绑定当前 Pane 的 provider/session 时才显示会话复制、历史与 Branch 动作。Info 当前可见时约每三秒更新一次，非终端 Pane 或检查失败会明确说明，不会冒充为空结果。Outline 页会实时显示运行中、成功或失败的终端命令（需要 Shell Integration，含状态与相对时间，点击或右键 Jump 跳回原位置，并可复制文本），也显示精确绑定会话的 Agent 提示词，以及 Markdown、HTML、JSON、YAML、TOML、Diff 与 JSONL transcript 的文档结构；连续编辑会自动合并刷新，点击条目跳到对应行。Git 页显示分支、+/− 统计与按暂存状态分组的变更。Commit 和编辑器控件都以“主动作 + 下拉箭头”共用一块圆角背景呈现；下拉仍有独立悬停和按压反馈。Commit 下拉提供 Push、Pull、Fetch、Merge… 和 Rebase…，选择后立即把对应命令预填到终端；Merge 与 Rebase 会先让你填分支名。右侧按钮用本机已安装的编辑器（VS Code、Cursor、Xcode、Zed）打开当前目录；从箭头菜单选择编辑器会记住该选择并立即打开当前目录，不必再点一次主按钮；没有检测到编辑器时该按钮不显示。把鼠标移到某个变更上，行尾会出现三个动作：暂存（已暂存的行是取消暂存）、在编辑器中打开这个文件、以及预览。预览会在面板左侧贴着面板打开一个只读 diff 气泡，右侧的尖角指向对应的那一行；按 `Esc`、点击气泡外或切走 Git 页即可关闭。**所有仓库写操作都只把命令预填到终端输入行**，包括 Commit、暂存、Push/Pull/Fetch 与 Merge/Rebase：确认后由你回车执行，Aster 不在后台跑写命令。分支名与文件路径会按 Shell 规则转义。Files 页以当前 CWD 为根显示有界目录树，目录与文件图标使用压低饱和度的淡强调色、文件名保持默认前景；目录首次加载时默认收起，只显示顶层文件与目录；点击箭头或双击目录在树内展开/折叠，Find 搜索会临时展开匹配路径。Find 旁可切换目录优先排序，以及用眼睛图标决定是否**一并列出**隐藏文件（默认不包含，开启后普通文件与 `.gitignore`、`.build` 等隐藏项一起显示，不是只显示隐藏项；隐藏目录只显示名称、不展开其内部海量文件）。Files 右键菜单固定为 Open、Open in Aster（当前 Pane、新标签、新窗口和四向分屏）、新建/重命名/废纸篓、路径复制和 Finder；目录展开仍只由 chevron 或双击负责。**Git 与 Files 两页的文件都要双击才打开**——单击只用于浏览，不会因为误触在工作区多开一个 Pane；Git 页也可以用行尾的编辑器图标或预览图标。大目录只渲染当前可见行，搜索输入不会重建搜索框。Info、Git 和 Files 按当前选中页独立加载，互不等待。在终端中切换目录时，旧树会保留到新目录读取完成后平滑替换，终端输入焦点不会移到详情面板。

在不同 Pane 之间切换时，详情面板会保留当前内容，等新 Pane 的 Info、Outline、Git 或 Files 结果准备好后一次替换，不再先清空列表。刷新期间旧内容不可点击；检查超过很短时间时，右上角会显示“正在更新…”提示，完成后自动恢复操作。

详情面板关闭时，只有右侧 Panel 本身保留折叠动画；中央终端区一次补到最终宽度，不会被显示层再次拉伸，动画末帧也不会因临时分隔线再跳 1pt。右上角始终是同一颗固定位置的图标，关闭过程不移除、不替换；Panel 完全关闭后再停留 650ms，鼠标已离开标题栏时才淡出。

## Recipes 与会话恢复

“显示”菜单可把当前标签保存成 `.ottyrecipe`，或重新打开 Recipe。Recipe 可保存 tab/window 作用域、完整嵌套分屏及比例、Pane 类型、目录、文件、可选命令和内容级别，不保存 PID、令牌或文件描述符。每次打开都会生成新的 Pane 身份，因此同一 Recipe 可安全重复使用。外部 Recipe 必须是受大小限制的普通文件，引用的编辑资源也有累计预算。

外部 Recipe 的命令默认先完整列出全部命令并确认，不会隐藏第 21 条及后续内容；可在“设置 → Recipes”选择从不重放、一次确认、逐条确认或仅对相同 SHA-256 内容信任。信任跟随文件内容而非路径，文件修改后必须重新确认。“逐条确认”会在每条命令真正写入终端前提供运行、跳过和停止选项。命令只在 Shell Integration 已就绪且停在空闲 Prompt 时串行发送，上一条收到完成标记后才发送下一条。

误关 Pane 或标签后按 `⇧⌘T` 可按最近关闭顺序逐个恢复。关闭历史跨正常退出和崩溃保留；正常退出会恢复主窗口和仍打开的附加窗口，连续崩溃三次会绕过可能损坏的快照并打开干净 Shell。可序列化布局会恢复，但不会持久化 PID、文件描述符或只读等临时状态。

## CLI 与深链

在“设置 → 通用”安装 `aster` 后，可从 Shell 控制工作区：

```bash
aster open ~/project --title API
aster view README.md --right
aster edit Sources/App.swift --new-window
aster jump project
aster learn ~/project
aster ignore ~/Downloads
aster pane capture --lines 100 --format json
aster pane send-text 'npm test\n'
aster pane run -- npm test
aster pane exec --format json -- git status --short
```

`open/view/edit/jump/learn/ignore/capture` 是只读或工作区动作；`pane send/run/exec` 必须先在“设置 → 控制 → IPC”开启“允许发送输入”，SSH 或 sudo 等敏感会话还需单独开启“允许敏感会话”。CLI 使用当前用户专属的 `0600` token 和普通文件请求通道，不监听网络端口。应用在异步请求期间意外退出时，新实例会把遗留请求明确结束为失败，而不会让 shell 持续等待完整超时时间。`aster://learn?...` 深链只处理有界目录学习请求；`ssh://` 只预填命令，不自动执行。

## Working with Agents

Aster 支持 Claude Code、Codex、OpenCode、Cursor CLI、Kimi Code、Pi 和 omp。在“设置 → 智能体”可启用 provider、安装/卸载受管 lifecycle 集成，并为 wrapper、环境配置或自定义可执行文件设置结构化启动命令。安装和卸载只改动带 Aster 标识的 hook/plugin；用户自己的配置保持不变，变更后应重启对应 Agent。

- lifecycle hook 把 `processing / idle / awaiting-input` 归一到所属 PTY，驱动标签徽章、完成/等待通知和“处理期间阻止睡眠”。不会读取或保存 prompt 正文。
- “Agent 历史”与 Open Quickly 可搜索已知 provider 的本机会话记录，并使用 provider 原生命令 Resume 或 Fork；不支持 Fork 的 provider 会明确拒绝。
- Composer 支持多行草稿、普通文件附件、固定/浮动与取消；发送时使用 bracketed paste，仍服从只读和粘贴保护。Prompt Queue 只按 lifecycle hook 的 `idle` 自动派发，`processing` 与 `awaiting-input` 都只排队；未安装 hook 时不自动发送，每一项都由你点击左侧发送图标提交。
- Send to Chat 可接收终端选区、当前可见 transcript 或文件上下文。上下文被包在 `untrusted-context` 中，移除终端控制字符、遮盖常见密钥并执行 128 KiB 总预算；Aster 不声称能识别所有业务敏感信息，发送前仍应复核。终端发送面板会以普通键入预填目标 Agent 输入框，最终提交始终由你决定。

## 九类设置

设置使用唯一独立窗口，固定为 `700 × 460 pt`；打开后主工作区保持原尺寸、原内容并完整可见，运行中的终端不会中断。设置窗口不能拖动缩放，黄色最小化与绿色缩放按钮禁用，点击红灯只关闭设置窗口。侧栏延伸到设置窗口顶部，左侧导航占满整行并保持左对齐；右侧内容按「分组标题 + 圆角卡片」组织，从页面顶部开始，卡片标题、说明与控件文字统一比左侧导航小一档。开关会先就地响应，普通切换不再重建整页；页面结构确实变化时才合并刷新，并保持当前滚动位置。内容较长时可以使用右侧滚动条访问。外观页的“左侧 Panel 宽度”和“右侧 Panel 宽度”编辑最近活动的工作区窗口。

- **通用**：界面语言、启动行为、窗口关闭行为、关闭标签页 / 窗口 / 面板的确认策略，以及系统集成（注册为 ssh:// 链接的默认终端、安装 `aster` 命令、Finder「在 Aster 中打开」服务、完全磁盘访问入口）。
- **Shell**：登录 Shell、`TERM`、Shell/SSH 集成、常用目录自动记录、会话恢复、系统通知权限、命令/watch/应用通知、前台策略、通知声音、BEL 和标签徽章。`TERM` 默认填写 `auto`，实际使用兼容的 `xterm-256color`；只有本机存在对应 terminfo 时才采用自定义名称。
- **控制**：Autocomplete / inline suggestion、Option/Meta、TUI 鼠标、焦点跟随鼠标、线性/矩形选择、复制清理、危险粘贴与 bracketed paste、OSC 52 读写权限、文件与链接 scheme/安全例外、平滑及首尾滚动、链接预览与自动安全输入。
- **编辑器**：自动换行、行号、不可见字符、Tab 宽度、滚动越过末尾、Vim 按键与富文档预览。
- **智能体**：七类 Agent 的启用状态、结构化启动命令、集成安装/卸载、标签徽章、通知与运行选项。
- **外观**：当前工作区左右 Panel 宽度、标签位置与自动隐藏、窗口尺寸、Dock 任务状态、浅深色主题、主题编辑/导入、文本样式、字体来源与回退、光标颜色/样式/闪烁/动画。
- **Recipes**：命令重放与按内容信任策略；外部命令必须按所选策略确认。
- **快捷键**：查看内置快捷键。
- **高级**：自动进度命令、标题修改/读取权限、导入/导出 JSON 配置、重置和运行内核信息。

全局设置可随配置保存与导出；左右 Panel 宽度属于工作区窗口，仅随对应工作区保存，不包含在配置导入/导出中。通知最终是否显示还取决于 macOS“系统设置 → 通知”中的应用权限和横幅样式。

## 常见问题

### 为什么窗口缩窄后 Panel 看起来小于设置值？

Aster 会优先给中央内容保留可操作空间，窗口不足时临时压缩右栏、再压缩左栏。这不会覆盖保存值；把窗口拉宽后会自动恢复。若要隐藏某一栏，请使用标签栏折叠或详情面板开关，不能通过拖动分隔线隐藏。

### `vim` 或 `top` 显示不正常？

确认“设置 → Shell → 终端类型”为 `auto`（或本机真实安装的 terminfo 名称），并开启“控制 → 允许鼠标报告”。无效的自定义名称会在 Pane 中显示启动告警并自动回退到 `xterm-256color`。

### 输入 `exit` 后怎么办？

该 Pane 会保留历史但标记为结束。关闭 Pane，或新建标签/分屏即可启动新 Shell。

### Recipe 会自动执行命令吗？

取决于“设置 → Recipes”的重放模式。默认会先显示命令预览并确认；选择“从不”时只恢复布局，选择信任时也只信任当前 SHA-256 内容，文件修改后会再次询问。命令按空闲 Prompt 串行重放，不会直接交给独立 `/bin/sh` 执行。

### 关闭编辑器时会丢内容吗？

不会直接丢弃。存在未保存内容时，关闭 Pane、标签或退出应用都会询问“保存 / 不保存 / 取消”；保存失败会阻止关闭。

## 外观主题

### 选择主题

打开“设置 → 外观”，在主题卡片中选择预设（每行四张卡片，窗口拉宽时卡片同步变大）。Aster 内置与 Otty 1.3.1 对齐的 9 个浅色主题和 15 个深色主题；选择后，无需关闭设置窗口，工作区和已经打开的终端会立即更新。开启“深色模式使用独立主题”后，可以分别选择浅色与深色主题。

需要快速比较时，使用“显示 → 主题”。这个选择器与 Otty 一样支持搜索；按上/下方向键或把鼠标移到某一行，左右 Sidebar、标题栏、中央终端背景和文字会立即预览。点击主题或按回车保存；按 `Esc`、点到面板外或切到其它应用会取消，并恢复打开选择器前的主题。

Glass Light 与 Glass Dark 会保留主题的真实透明值，由 macOS 原生材质显示桌面内容；截图里看到的灰度只是当时桌面与材质合成的结果，不会被保存成固定背景色。所有分屏会同时切换，不会因活动状态出现一边黑、一边仍是旧主题。Floating Card、Nord、Pink、Monokai Classic 等主题会同时使用各自的光标文字色和选区前景/背景，不再用通用近似色替代。9 套浅色主题的窗口、容器、左右 Sidebar、标签栏、标签、终端、光标、选区和 ANSI 色都直接采用“详情”中显示的最终色值；中央标题和 Pane 共用连续背景面，只保留路径胶囊本身的标题文字与显式底色。浅色主题没有单独定义选区时，默认使用 30% 透明的终端前景色。

### 创建和编辑主题

1. 选中一个主题，“详情”里会展示这套主题的完整色板：上方是终端前景/背景与 ANSI 16 色，下方按 Window、Container、Panel、Sidebar、Titlebar、Tabbar、Tab、Accents、光标、选区分组列出每个颜色。把鼠标停在色块上会显示它对应的 token 名与色值（例如 `前景色 · terminal.foreground = "#2a2b33"`），点击色块会在旁边弹出取色器（色域 + 色相条 + 透明度条 + 可粘贴的 hex 输入）直接改这一个颜色。**改色不会复制出一套「副本」主题**：Aster 只记下你改过的那几个颜色作为覆盖，叠在原主题之上，同时写进 `~/.config/otty/themes/<theme-id>.ottytheme` 末尾的 managed 段（每项带 `# otty-added:` 注释）。改过之后详情区会出现「恢复主题原色」，点一下会从应用覆盖和 Otty 文件中一起删除这段个性化设置。**画着斜线的色块表示这套主题没有单独设置它**，它当前的颜色是从 Window 一侧推导出来的——改 Window 颜色时，这些色块会跟着变，已经单独设置过的则不会。Sidebar 一组同时作用于左侧标签栏和右侧详情面板；修改容器或选中标签的边框颜色时，原本没有边框的主题会自动显示 1pt 边框。设置页自身的配色不跟随终端主题，换主题不会让设置页变色。
2. 点击“复制”创建可编辑副本；内置主题不会被覆盖。
3. 点击“编辑当前主题”，修改名称、明暗模式、窗口/容器/面板颜色、文字、强调色、光标、选区及 ANSI 颜色。
4. 点击颜色块调用系统取色器；点击“保存”后同时写入应用配置和主题文件夹，取消则放弃草稿。

主题名称不能与现有主题重复。编辑失败时，Aster 会保留草稿并显示原因。

### 导入主题

点击“导入主题…”选择 `.astertheme` 或 Otty 的 `.ottytheme` 文件。Aster 只接受 256 KiB 以内的普通文件，不读取符号链接、FIFO 或设备文件，并在加入主题库前检查名称和完整的 ANSI 16 色。你可以直接从 `~/.config/otty/themes` 选择已有 Otty 主题；点击“打开主题文件夹”可以查看 Aster 复制、编辑和导入后的文件。

### 文本与字体

“文本”区域可以调整字号、粗体、斜体、下划线、终端闪烁文字、连字、字体平滑和行高，修改会立即应用到已经打开的终端。行高调整的是每行的网格高度和留白；竖线光标严格按当前字号绘制，不会随字体额外 leading 或行高向上伸入上一行。光标每帧都会先清除旧像素，切换样式或连续输入时不会留下整格残影。

“字体”区域按四个作用范围展示：

- “计算值”显示当前实际采用的普通、粗体、斜体和粗斜体字体。
- “全局”设置所有主题共用的四种字体；留空时继续向后解析。
- “主题”读取当前主题的 `font-mono` 候选。内置主题需先复制，才能修改候选列表。
- “回退”只在主字体缺少字符时补字；Aster Nerd Symbols 始终优先保证 Powerline 和 Nerd 图标可见。

如果只设置普通字体并开启“自动匹配粗细与样式”，Aster 会从同一字体家族寻找粗体、斜体和粗斜体。找不到时会安全回退到普通字体。

### 光标

“光标”区域提供主题颜色或自定义颜色、光标下方文字颜色、不透明度、方块/竖线/下划线/空心方块、闪烁优先级和平滑动画。预览会同步显示当前组合。

闪烁优先级决定终端程序能否控制光标：

- “默认关闭 / 默认开启”只决定初始状态，vim、Claude Code 等程序之后仍可通过 DECSCUSR 改变形状和闪烁。
- “始终关闭 / 始终开启”固定你选择的形状与闪烁状态，忽略程序后续请求。

窗口失去焦点时，光标会保持形状但停止闪烁。平滑动画仅处理同一行的短距离移动，并遵循 macOS“减少动态效果”设置。

### Dock 图标

“任务进行时旋转”会持续增加 CPU 与电量消耗，因此默认关闭；“出错时变红”可帮助定位失败标签；“收到通知时跳动”只在 Aster 不在前台且系统允许时触发。这三个开关彼此独立。
