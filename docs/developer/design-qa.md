# Design QA

## 验收边界

功能实现以代码测试、静态检查和构建为本轮自动验收范围。按项目要求，不运行鼠标、键盘或真实窗口自动化；以下视觉与交互检查由用户在打包应用中完成，结果回填到本文。

## Controls 检查清单

- [ ] 控制页依次显示 Autocomplete、Selection、Scroll、Open With、Link Protocols、Keyboard、Mouse、Secure Input、Clipboard 九组，字段顺序、文案、枚举和值依赖关系与 Otty 一致。
- [ ] 左/右/全部 Option-as-Meta、VT100 application keypad、右键动作、鼠标报告绕过键、鼠标隐藏、focus follows mouse 和安全输入指示会立即作用于已有 Pane。
- [ ] “Open With”自定义应用可通过系统应用选择器添加和移除；文件夹与 Git 仓库按设置的 Aster、系统应用或 Git 客户端打开。
- [ ] 自定义链接协议仅接受合法 scheme；预览开关、鼠标模式下链接点击和外部打开安全确认符合设置，重置后再次询问。
- [ ] 补全清理弹窗可分别清除历史、固定命令和常用目录；取消不改变数据库或目录频率状态。

## Selection / Scroll 检查清单

- [ ] 拖动、双击和三击分别选择字符范围、单词和整行。
- [ ] `Option` 拖动显示矩形高亮，复制文本按物理行保留列边界。
- [ ] 鼠标报告开启时，`Option` 选择不会触发 TUI 鼠标动作；`Shift` 遵循程序协商的捕获模式。
- [ ] `Shift+Arrow` 线性扩展可跨锚点收缩并反向扩展；加 `Option` 后显示矩形高亮。
- [ ] 设置中的输入清理、复制清理和 Shift 方向键开关立即作用于已有 Pane。
- [ ] 触控板滚动连续且无字符行撕裂，手势结束后对齐完整行。
- [ ] `Shift+Page Up/Down` 与 `Shift+Home/End` 作用于当前 Pane。
- [ ] 首尾四种停靠模式符合设置文案；进入 vim、less 等 alternate screen 后不出现越界空白。
- [ ] 新输出和键盘输入会回到最新内容，设置窗口切换滚动选项时布局不抖动。

## Shell Integration / Identification 检查清单

- [ ] 新建 zsh、Bash、fish Pane 后，目录变化可同步，提示符不出现可见 OSC 字符。
- [ ] `Command+Page Up / Page Down` 连续跳过多条命令，首尾没有反向跳动。
- [ ] 命令运行时标签显示 spinner；结束后按设置显示 `✓` 或非零退出码。
- [ ] 提示符内选择 ASCII 文本后按 Backspace 或 Cut，只删除选区；跨行或 Unicode 选区保持无损降级。
- [ ] 混合英文、希伯来文/阿拉伯文、数字和路径按阅读顺序显示；鼠标、caret 与左右键对齐，复制结果仍为逻辑顺序。
- [ ] 标准与 discretionary 连字不会挤压后续网格列；宽字符、下划线、背景和选择区域仍按单元对齐。
- [ ] iTerm2、Kitty 与 Sixel 示例图片尺寸正确；损坏或超限输入不残留旧图，也不阻塞后续文字。
- [ ] 关闭 Shell Integration 会显示确认并移除受管区块；重新开启不会重复追加 marker。
- [ ] `TERM=auto` 下 `echo "$TERM_PROGRAM $TERM"` 显示 `aster xterm-256color`；DA/XTVERSION 探测工具识别为 Aster。
- [ ] 同一标签的不同 Pane 分别运行 Codex、Claude 或普通 Shell 时，每次展开“Shell”菜单只显示当前聚焦 Pane 对应的 Agent 子菜单；Fork 到四向分屏、新标签和新窗口后目录与会话连续。菜单展开后即使设置页或其它工作区成为 key window，Fork 仍落到原工作区。没有可信 session ID 时复制与 Fork 保持禁用。

## Autocomplete / Inline Suggest 检查清单

- [ ] zsh、Bash 和 fish 的提示符停顿后显示 ghost；Backspace 和 Escape 立即清除旧候选。
- [ ] 默认第一次 Escape 关闭 ghost，第二次打开面板；上下键、Return、Tab 和点击均只接受候选、不自动执行命令。
- [ ] 候选面板跟随光标并在上下空间不足时翻转，最多显示 8 项，长描述不撑破 Pane。
- [ ] 快速连续输入时，inline ghost 等 Shell 回显更新光标后再出现，不覆盖已输入命令。
- [ ] Tab、Tab 或 Right、Control-Space、关闭四种接受策略立即作用于已打开 Pane。
- [ ] 文件、目录、alias、历史、README、纠错与 `aster learn` 候选分别显示正确类型。
- [ ] 关闭本机学习后不再出现历史/README/纠错，也不启动 help 探测；文件与内置命令仍可补全。
- [ ] 设置页“立即更新”只在点击后联网；“清除”移除学习和固定命令但保留本地 help 规格。

## Vi / Hint / Read-only 检查清单

- [ ] `Control+Shift+Space` 只让当前 Pane 进入 Vi；计数移动、三类选区、复制退出和 `Escape`/`q` 退出均不向 Shell 输入字符。
- [ ] `Command+/` 只在 Vi/Mark 中切换底部按键提示，提示不遮挡右上角模式 pill。
- [ ] Hint 标签贴合当前可见 URL、OSC 8 链接和文件路径；普通标签键打开，Shift 最终键只复制，输出改变后旧标签立即消失。
- [ ] Read-only pill 只出现在锁定 Pane；键盘、IME、粘贴及 TUI 鼠标报告被拒绝一次，滚动、选择、复制、查找和持续输出不受影响。
- [ ] Read-only 中进入 Vi/Hint 会隐藏 pill，退出后 pill 与锁恢复；编辑器切换只读后不可输入，关闭重开后默认解除。

## Progress / Notifications 检查清单

- [ ] OSC 9;4 百分比与不定进度同时更新终端顶部进度条和标签；成功先显示 checkmark，随后变为圆点。
- [ ] password、`[y/n]` 与 Press Enter 提示静置约 1.5 秒后显示等待输入，输入后立即清除。
- [ ] `aster watch`、`-q` 和 `aster tab badge` 的徽章、退出码与通知行为符合帮助文档。
- [ ] OSC 9、777、99 在应用后台、前台未聚焦标签和前台聚焦标签下分别服从策略。
- [ ] Shell Controlled、通知声音、BEL、错误 beep 和 Dock 弹跳互不串联。
- [ ] Dock 运行动画默认关闭；错误标红默认开启，点击图标跳到失败标签并清除当前红色状态。
- [ ] macOS 通知权限状态从系统设置返回后自动刷新。
- [ ] 关闭标题 Shell Controlled 后程序不能改名；标题报告关闭时查询只能收到空值。

## Window / Details / Drag 检查清单

- [ ] `⌘N` 创建独立工作区；退出重开后恢复仍打开窗口，主动关闭的附加窗口不复活。
- [ ] 垂直标签布局下拖动左 divider 可在 180...360pt 调整 Sidebar；展开详情后拖动右 divider 可在 240...480pt 调整 Inspector；悬停均显示强调色与左右光标，双击分别恢复 220pt / 278pt，拖到边界不会折叠。
- [ ] 两个工作区分别设置不同左右 Panel 宽度后互不串值；独立设置窗口编辑最近活动的工作区。窗口缩窄时 Inspector、Sidebar 只临时压缩，重新拉宽后恢复保存值，终端与详情视图身份不变。
- [ ] `⌘,` 打开并复用唯一独立设置窗口，主工作区保持原尺寸、原内容且完整可见。内容只有一个非持久化 `WKWebView`，资源全部来自签名 Bundle，网络请求和目录外导航均被拒绝。九类导航、搜索、开关、主题、Agent、Recipe 与快捷键录制可用；普通设置即时写入且不替换工作区终端树。默认内容尺寸 `700 × 460 pt`，最小尺寸相同，窗口可继续拉大并记忆尺寸，超出内容由网页滚动承载。
- [ ] 标签拖到另一个窗口或窗口外后，原终端命令、滚动历史、标题和 Agent 状态连续；源窗口始终至少保留一个标签。
- [ ] 垂直侧栏标签行默认显示 shell/运行状态，悬停时在同一固定槽位显示 `×`，标题不位移；点击可关闭对应标签，关闭后台标签不改变当前选中项。
- [ ] 终端内容延伸到容器底部，不再出现 `workspace · path / PANE / UTF-8` 状态栏，外观设置中也没有无效的状态栏开关。
- [ ] Pin 只置顶当前工作区，独立设置窗口不改变置顶状态；PiP 的“当前 Pane”和“跟随活动 Pane”切换正确，主题或工作区刷新时 PiP 不变空，主窗口显示占位，关闭后同一终端恢复。
- [ ] Finder 文件/目录拖到 Pane 四边时高亮方向正确；内区终端、外区文件浏览器、文件预览和文本粘贴符合帮助文档。
- [ ] 详情面板的信息、大纲、Git、文件页跟随聚焦 Pane；只启动当前页的检查，慢进程/端口/Git 不阻塞终端输入，切页、收起或连续 `cd` 后旧任务及时取消。
- [ ] Files 页打开时连续执行 `cd`，旧树到新树的替换无空白或加载态闪烁，终端无需再次点击即可继续输入。
- [ ] 首次打开详情面板可立即交互；展开/收起不替换终端、侧栏或 first responder；Info / Outline / Git / Files 往返切换和同标签收起后重开不重复构建页面。
- [ ] Inspector 展开时右上折叠按钮常显且窗口坐标固定；收起过程中不闪出标题栏副本，Panel 内容与边界同步向右折叠；收起完成后同位置入口短暂停留，鼠标离开标题栏约 650ms 后淡出，移回标题栏立即显示。
- [ ] Files 首次加载默认收起目录并仅显示顶层行；在 500 项目录中搜索、排序、展开和滚动时只渲染可见行，搜索框身份与焦点稳定；目录/文件图标为压低饱和度的淡色、文件名默认前景；Find 旁眼睛默认不包含隐藏文件，开启后普通项与隐藏项一并列出（不是只显示隐藏项；大隐藏目录如 `.build` 不展开内部）；右键菜单严格包含 Open、Open in Aster placement、新建/重命名/废纸篓、路径复制和 Finder，目录展开不混入右键菜单；双击目录只在树内展开；Git 和 1,000 条 Outline 同样使用虚拟化行，连续编辑只显示最后版本。
- [ ] Info 只在当前可见时每三秒刷新；终端 Pane 显示含 shell 根的本地进程树、去重 listener 和失败/不可用提示，收起或切页后不再轮询。
- [ ] Outline 在终端命令运行中、完成和 Markdown 等文档编辑后实时出现条目；状态图标区分运行/成功/失败，点击或右键 Jump 跳到正确终端位置或编辑器行，Copy Text Content 始终复制条目文本。
- [ ] Agent Info 与 Outline 只显示 lifecycle hook 精确绑定当前 Pane 的 provider/session；切换 Pane 不出现其他 Pane 的 prompt 或 session action。
- [ ] 标题栏背景与文字分别采用主题详情中的 `titlebar.background` / `titlebar.foreground`；普通状态显示程序标题，悬停显示缩写 CWD 路径胶囊，点击弹层中的名称/前缀、路径、Finder/编辑器、Git、通知、分屏、查找与命令面板动作均可用。
- [ ] 详情面板页签在默认状态下保持等宽收起与统一间距，悬停有淡底色反馈；点击后当前页签平滑展开出名称、其余收起，图标位置不横向漂移；系统开启「减弱动态效果」时直接切换。
- [ ] Git 页写操作全部只预填到终端输入行而不直接执行：Commit 主按钮、下拉中的 Push / Pull / Fetch，以及需要填分支名的 Merge… / Rebase…（分支名为空或以 `-` 开头时不注入任何命令）。
- [ ] Git 页的 Commit 和编辑器控件均由主动作与下拉箭头共用一块圆角背景，分段悬停与按压反馈清晰；编辑器按钮显示本机已安装编辑器的图标与名称，主按钮打开当前目录，箭头菜单选择后保存默认项并立即打开当前目录，无需二次点击；未安装受支持编辑器时按钮与行内编辑器图标都不出现。
- [ ] Git 与 Files 页的文件单击不打开任何 Pane，双击才在工作区打开；Outline 条目仍是单击跳转。
- [ ] Files 双击 Markdown/HTML/SVG/RST 和源码默认进入可编辑 Source；前四类的 code/eye 往返和源码 code/lock 往返无明显卡顿，保留选区、滚动与 undo，且不替换同一 `NSTextView` / `WKWebView` 或终端视图。
- [ ] Info / Outline / Git / Files 的列表行悬停时整行出现底色，Staged/Unstaged 分组标题行不出现；行内可点图标（暂存、展开目录、预览、关闭）悬停时有自身底色并加深、指针变成手型，文件名与大纲条目悬停时指针同样变成手型。
- [ ] Git 变更行悬停才出现暂存（已暂存行为取消暂存）、在编辑器中打开、预览三个图标，移出后隐藏且分组行不残留图标；图标隐藏再出现时不残留上一次的悬停底色；预览打开的只读 diff 气泡右缘紧贴详情面板、尖角对准触发行，增删行分别着色；顶部文件名压在 `#EFF4FF` 标题条上，标题条贴气泡顶边、只在上方两角圆角；该底色与条上前景色固定不随主题变化，深色主题下文件名仍清晰可读；关闭按钮在标题条右端且不与尖角重叠；行贴近窗口上下边缘时气泡整体夹回窗口内而尖角仍指向该行；缩放窗口后气泡不脱离面板；`Esc`、点击气泡外或切走 Git 页都能关闭。
- [ ] 全局查找和 Open Quickly 的八类过滤器可跳回正确窗口、标签、Pane 或资源。
- [ ] Open Quickly 可反复打开而不重建侧栏或终端，也不触发 Auto Layout 异常；打开后搜索框立即获得输入焦点，点击搜索框不关闭浮层；面板有清晰但克制的 scrim + 阴影层次，点击外部可关闭，搜索框无蓝色系统长条 focus ring，搜索图标与 placeholder 留有明确间距且垂直居中；鼠标只在 36pt 搜索区显示文本光标，其余区域显示普通箭头；搜索框、chip、结果和底栏横向基线一致，结果行选中背景占满内容宽度；顶部标签条切换过滤时复用行且选中 chip 高亮正确；结果行显示图标、相对时间与类型徽章；「全部 / 当前」视图按分组显示小节标题，结果超出时可滚动。
- [ ] Open Quickly 键盘路径完整：`↑`/`↓` 循环选择、`↩` 跳转、`Esc` 关闭、`⌘1`–`⌘9` 按可见顺序快速选中、`⌘K` 弹出操作菜单（关闭标签、Fork 会话、在 Finder 中显示、复制提示词）。按住 `⌘` 时 chip 显示 `⌘0/W/R/Z/S/G/J/E`、前九条结果显示 `⌘1`–`⌘9`，松开立即隐藏且水平布局不跳动。切换到其他应用，或在 Aster 窗口的浮层外部（含标题栏）用任意鼠标键点击，面板立即隐藏。
- [ ] Open Quickly「当前」页显示各 Pane 正在运行的前台命令名（Cmd 徽章）；运行 Agent 的 Pane 出现「提示词」分组，点击提示词粘贴回该 Pane 输入行且不自动回车。
