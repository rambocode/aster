### 手机/平板用户自测步骤

1. 在手机 SSH 客户端（如 Termius、Blink Shell、iSH 等）连接 OrbStack 远端：`ssh root@<orbstack-ip>`
2. 运行 `aster-session ui <state-parent> <name>`（state-parent 为会话状态目录，name 为会话名）
3. 观察要点：
   - 状态栏是否在底部渲染（窄屏模式：`^Bq=quit`）
   - Ctrl+B q 是否正常分离（退出 TUI 后 shell 可继续输入）
   - Ctrl+B n/p 是否切换标签（如有多个标签）
   - Ctrl+B o 是否切换窗格（如有分屏）
   - 文本输入是否正常传递到终端并可见输出
   - 触屏点击是否触发窗格切换（取决于 SSH 客户端是否发送 SGR 鼠标序列）
4. 记录：设备型号、SSH 客户端名称与版本、屏幕尺寸（列×行）
