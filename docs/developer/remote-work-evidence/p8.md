### 2.4 20 终端高输出不稳定修复

**根因（4 个复合问题）：**
1. `Pool.tick()` 无聚合读取预算——每终端读 64KB，20 终端 = 1.28MB VT 处理/tick，线性增长
2. `enforceHistoryBudget()` 在每个产出输出的终端后调用——O(n²)：20 个活跃终端 = 20 次调用 × 20 条目 = 400 次遍历/tick
3. `waitResources` 轮询 PTY FD，高输出终端总有数据，poll 立即返回——100% CPU 忙循环
4. `persistScreenHistory` 每次循环对所有终端执行 `snapshotForClient`——间隔检查在 `maybePersist` 内部，昂贵的截取已完成

**修复（4 文件，119 行新增 / 23 行删除）：**
- `session.zig`：`tick()` 新增 `read_budget` 参数（原硬编码 65536）
- `terminal_pool.zig`：聚合预算 128KB / 终端数（下限 4KB）；`enforceHistoryBudget` 从每终端改为每 tick 调用一次
- `service_server.zig`：`waitResources` 在有活跃输出时最大等待 1ms（防忙循环）；`persistScreenHistory` 在遍历终端前先检查间隔
- `probe.zig`：适配 `tick()` 新签名

**测试（红/绿）：**
- 新增测试：`"20 high-output terminals stay bounded: aggregate budget prevents busy-spin"` — 创建 20 终端各运行 `seq 1 5000`，全部完成无失败
- Zig 全套 47/47 通过（含新测试）
- Python 集成测试 6/6 通过：terminal_attach, surface_service, bridge_foreign_events, agent_hook_directive, tui_bridge_survival, cold_restore

## 10. 退出码平台边界（补充说明）

macOS kqueue NOTE_EXIT 和 Linux pidfd_open 均无法获取 adopted（非子进程）终端的真实退出码。两平台测试中 `exit 42` 的终端均报告 exitCode=0。根因：
- macOS：`kevent` 的 `data` 字段对非子进程只返回 0
- Linux：`pidfd_open` + `waitid` 对非子进程返回 ECHILD

两平台均以 PTY EOF 作为退出检测兜底（PTY master fd 可读 0 字节 = slave 关闭 = 进程退出）。exitCode 在两平台均标记为"非子进程不可得"。显式结束（terminate）的退出码由信号决定，已在既有 handoff e2e 测试中验证。

## 11. P8 收尾修复（2026-09-12 第二轮）

### 11.1 Issue 1：接管前失败回退（A22 / P8.5）

**根因**：`runTakeover` 在获取锁和收养终端之前就发送了确认。新服务在确认与锁获取之间被杀时，旧服务已关闭 PTY FD 并退出。

### 11.2 Issue 2：macOS 被接管终端的真实退出码（A22）

**根因**：macOS kqueue `NOTE_EXIT` 的 `event.data` 对非子进程始终返回 0，不含真实退出码。C 代码注释错误地声称它是 waitpid 格式。Linux pidfd 同样无法获取非子进程退出码。

**验证**：独立 C 程序 `exit 42` → kqueue `event.data = 0`；waitpid 正确返回 `0x2a00`（WEXITSTATUS=42）。

**修复**：
- `process_scope.c`：macOS `session_scope_poll_exit` 返回 `status = -1`（不可得），注释更正；Linux 同步为 `-1`
- `session.zig`：接管终端 `exit_status` 使用 watcher 原始值，不再 fallback 为 0
- `terminal_service.zig`：`activeTerminal` / `retiredTerminal` 中对 `-1`（0xFFFFFFFF as u32）检查 `status_i32 >= 0`，不满足时 `exitCode` 保持 null

**效果**：`terminal.list` 对接管终端的 `exitCode` 返回 null（不可得），不伪造 0。Linux 同样 null。

**改动文件**：
- `SessionRuntime/src/platform/process_scope.c`
- `SessionRuntime/src/session.zig`
- `SessionRuntime/src/terminal_service.zig`
